# AI Director OS 新手快速入口

你不需要知道任何 Skill 名称。只要选择想完成的任务，并提供最少材料；系统会自动选择能力。

## 先选任务

| 我现在想做什么 | 你最少需要提供 | 系统会交付什么 |
|---|---|---|
| 从一句创意做成完整短片 | 一句话想法 | 剧本→审稿→分镜→资产→视频提示词→交付清单 |
| 写剧本 | 创意、题材或已有大纲 | Logline、节拍、大纲或完整剧本 |
| 审稿/改稿 | 现有剧本 | 问题清单、改稿方向；需要时输出修订版 |
| 把剧本拆成分镜 | 已确认剧本 | 导演概念、生产镜号、时长、连续性和生成段 |
| 提取视觉素材 | 已确认剧本或分镜 | 角色、场景、道具、氛围资产和生图提示词 |
| 写视频提示词 | 已确认分镜；知道目标模型最好 | H3、Seedance或Fafajing提示词 |
| 继续已有项目 | 项目目录或 `simple-project.json` | 从当前步骤继续，不重问已知信息 |
| 做世界观和角色 | 一句创意种子 | 世界边界、主要阵容、关系和待确认提案 |

## 可以直接复制的说法

```text
我只有一个想法：______。请从剧本到视频提示词完整带我做，你决定低影响细节。
```

```text
这是我的剧本：______。请先检查剧情，再做可供AI视频生成的分镜。
```

```text
这是确认分镜：______。目标模型是 Seedance / H3 / Fafajing，请提取资产并写提示词。
```

```text
继续这个项目：______。读取已有文件，从未完成步骤继续。
```

## 系统只会询问真正影响方向的内容

通常只确认：

- 成片形态和时长；
- 横屏或竖屏；
- 核心关系和结局承诺；
- 视觉媒介；
- 最终视频引擎；
- 不能改动的设定。

角色小名、普通道具、次要装饰等低影响信息可以由系统提案，不会逐项盘问。

## 新手默认原则

1. 普通项目使用轻量底座，不展示复杂工程名词；
2. 剧本未确认前不进入正式分镜；
3. 分镜未确认前不批量生成资产和视频提示词；
4. 没有参考图时会明确标注，不会假装已检查；
5. 外部付费生成、发布和购买仍需要用户授权；
6. 用户随时可以只做一个环节，不必跑完整流程。

## 如果你完全不想做选择

直接说：

```text
你来决定，按最小可用方案继续；所有推断标成提案。
```

系统会采用紧凑默认值，并把真正无法代替你决定的事项集中成一次确认。
