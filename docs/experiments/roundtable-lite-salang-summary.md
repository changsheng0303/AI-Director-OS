# 精简圆桌真实项目基线：《沙浪之上》

> 文档版本：1.0  
> 更新日期：2026-08-26  
> 当前状态：完成剧本层诊断与V2候选影响估算；未执行视频生成A/B

## 项目概览

使用已完成六门常规自检的5分20秒运动成长动画短片，测试精简3视角圆桌能否在不触发全本重写的情况下发现增量问题。

## 目标与范围

- 三个视角：资深类型片编剧、核心受众观众、商业制片；
- 只诊断结构、受众体验和生产风险；
- 不修改正式剧本Canon；
- 不把结构化审稿结果宣称为实际视频效果。

## 当前状态

- 已完成：三视角证据式诊断；
- 已完成：只删除一条解释性台词的V2实验候选；
- 未完成：正式Dialogue Change Request、镜头重编和生成看片。

## 关键决策

1. 三位评委没有共同指出致命问题，因此不制造“必改”；
2. 只触碰解释同一转折的重复台词层；
3. 中后段运动疲劳问题交给分镜差异化，不继续删剧情；
4. 生产Canon保留V1，候选不自动生效。

精简圆桌在本案例中表现为“问题收敛器”：减少一层解释，对结构、比分、球权、角色弧和结局不做改动。

## 风险与问题

- 单项目不能证明普适性；
- 未进行独立盲评；
- 未生成V2视频；
- 正式删改固定台词仍需Dialogue Change Request。

## 下一步

1. 累积至少5个不同题材；
2. 记录每次触及场景、镜头和提示词比例；
3. 对批准的候选执行同资产、同模型、同参数A/B；
4. 结合实际返工次数决定精简圆桌是否保持默认3视角。
