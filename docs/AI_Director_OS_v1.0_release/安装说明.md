# AI Director OS 安装说明

## 适用对象

本包面向希望使用模块化 AI 导演系统的创作者、分镜师和 AI 视频制作人员。它默认作为一个 Codex Skill 使用。

## 安装步骤

1. 解压本分发包。
2. 将 `skill/cinematic-ai-2d-director` 复制到目标环境的 Skills 目录。
3. 将 `workspace-template/AI_Director_OS_CURRENT.md` 复制到具体项目根目录。
4. 在目标环境重新载入 Skills，或重新打开会话。
5. 输入“使用 AI Director OS”开始调用。

不同环境的 Skills 目录可能不同。不要把整个分发包的根目录直接当作 Skill 目录；真正的 Skill 根目录是 `skill/cinematic-ai-2d-director`。

## 推荐项目目录

```text
项目根目录/
├─ AI_Director_OS_CURRENT.md
├─ assets/
├─ story/
├─ storyboards/
├─ prompts/
├─ qa/
└─ failures/
```

## 推荐调用顺序

### 新项目

先让系统完成类型路由和缺失信息检查，再建立项目状态文件、角色/场景资产和第一版 Beat Chain。

### 已有剧本

要求系统先做剧本诊断，再转为 Director Storyboard，最后才编译为 AI Production Storyboard 和模型提示词。

### 已有视频

提供视频及其生成参数，要求系统先执行 Direct Video QA，记录问题码和失败等级，再决定是否做 A/B 修复。

## 生产前最低检查

- 主体、空间、左右关系和关键道具已锁定。
- 每个镜头有 Start State、Key State 和 End State。
- 重要物体有 Relative Scale。
- 关键身份、材质和非生物边界写入 Locked Features。
- 镜头之间有明确的切镜接口。
- 生成模型、时长、比例和参考资产已确认。

## 不能做的事情

- 不要把实验性 Action 规则直接提升为通用 Core。
- 不要用文字评分代替真实视频检查。
- 不要同时加载全部类型模块和全部 Adapter。
- 不要在没有用户授权或素材的情况下擅自生成外部服务任务。

## 升级方式

升级时保留旧版本分发包。先更新对应模块，再运行规则 QA、Storyboard QA、Generation QA 和 Regression QA，最后修改 `AI_Director_OS_CURRENT.md` 的状态。若只有理论规则或单个案例，状态应保持 Candidate/Experimental。
