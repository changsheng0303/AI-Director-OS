# 示例:日式住宅 7 场景资产卡(结构范本)

来源:《海风女子学园》项目,2026-08 产出。每个场景演示 7 维结构的写法。空间锚点与伏笔链是全套设计的骨架,提示词以最简示例展示风格标记与遮挡写法。

## 1. 玄関(土间玄关)｜开场场景

- **空间锁定**:下沉式三合土土间(冷硬哑光)→ 一级木台阶「上がり框」→ 榻榻米室内。**锚点:台阶=内外分界,过场戏全压在这条线上。** 鞋柜木屐/帆布鞋,木格雨户。
- **画面特征**:材质对撞(灰土间 vs 暖榻榻米);傍晚逆光从门缝灌入,浮尘在光柱可见;海风先吹门槛拖鞋绳,再传纸门(错峰)。
- **镜头**:归家=门内低机位剪影→俯拍脱鞋→侧拍上台阶;偷看=门缝过肩,前景木框压暗。门开合=搭框预备→弧线推→回弹。
- **声音**:海风低频、门轴吱呀、纸门鼓动、木屐清脆。
- **剧作功能**:归家线 + 窥视/隐藏信息场。**门缝=信息缝隙**,后续"门后有人"都靠此动线。
- **🎬 提示词**:`动漫 2D,赛璐璐平涂,anime style, cel shading。傍晚日式民宅玄关:三合土土间,光线从半开木格雨户逆光涌入,浮尘在光柱中可见。人物剪影踏入、脱鞋(俯拍)、踩上磨损发白的木台阶。海风先吹动门槛拖鞋绳,再使纸门下部鼓动,晚半拍停止。镜头:低机位固定,单镜头缓慢跟随,无切镜。`

## 2. 居間(客厅)｜家庭核心

- **空间锁定**:泛黄蔺草榻榻米、障子纸窗木格投影、中央矮桌「ちゃぶ台」、壁龛「床の間」(旧照片/挂轴)、可拆襖门通廊下。**锚点:ちゃぶ台=视觉与戏的重心,桌下=隐藏空间(变身戏的舞台)。**
- **画面特征**:夜晚和纸吊灯形成中心暖光区,四周渐暗;壁龛=家庭记忆角(伏笔可放海边旧照片)。
- **镜头**:变身戏=桌下仰拍(桌布掀动、人影晃动、光线明暗变化);主动作=心率表数字跳动→身体弓起蓄力→烟雾弧线爆发→桌腿位移(跟随)。
- **剧作功能**:日常浓度是变身的对照组——聚餐越扎实,兽化冲击越强。
- **🎬 提示词**:`...夜晚日式客厅:和纸吊灯暖光照亮矮脚长桌,四周渐暗。人物席地围坐,脸被桌灯照亮。镜头:桌面高度平视,缓慢横移绕过桌角。桌下阴影中白色动物身影弓起蓄力,浓密烟雾沿弧线从桌下涌出,桌腿轻推位移,烟雾在灯光中翻滚。保持人物身份、榻榻米纹理、吊灯位置不变,无切镜。`

## 3. 廊下(长走廊)｜转场核心通道

- **空间锁定**:原木地板(纵向纹理=屏幕方向基准)、木梁柱;一侧房间纸门,另一侧格子窗;夜晚仅房间漏光。**关键设定:卧室门全朝廊下,卧室看不到客厅——视线动线唯一化,走廊是秘密的容器。**
- **画面特征**:门缝底部光带=角色定位坐标;地板拖出灯光倒影;脚步空腔回响(深夜放大)。
- **镜头**:贴地跟拍穿梭,门框做前景遮挡转场(切镜动机=空间桥接);保持纵深方向不反跳(30/70 原则)。
- **剧作功能**:EP2 小狗跑向花穗卧室的连接器。
- **🎬 提示词**:`...深夜木构走廊:原木地板纵向透视,纸推拉门序列,门缝漏出不同色温光带,格子窗透月光。黑白边牧犬低机位跑过,爪步稳定,经过每扇门时光带短暂遮挡又恢复。镜头:贴地跟拍缓慢前移,门框前景遮挡过渡,保持纵深方向不变。`

## 4. 各寝室(和式卧室)｜私密空间

- **空间锁定**:榻榻米 + 押入れ壁橱(白天收被褥)+ 纸障子窗 + 夜晚木雨户。**每间房=角色人格镜像。**
- **花穗房**:窗边书桌、日记本 + 泛黄海边旧照片(伏笔锚点)、排球海报/漫画剪报;深夜台灯局部光锥,房间沉入阴影——独处/独白戏。
- **绪/沙耶房**:毛绒玩偶/随性零碎,默认只拍推门远景(信息含量低,节奏快)。
- **🎬 提示词**:`...深夜和式少女卧室:暖色台灯光锥照亮窗边矮桌,摊开日记本与泛黄海边旧照片,木墙钉排球海报,房间其余沉入深蓝阴影。人物侧坐指尖轻触照片边缘,发丝垂落。窗外月光渗入。镜头:缓慢推近至照片特写,台灯光线方向恒定。`

## 5. 台所(日式厨房)｜深夜静场

- **空间锁定**:半土间、木料理台、陶制烧水器、和纸小夜灯、木搁板碗碟;无主采光窗,夜晚局部照明。
- **画面特征**:小夜灯+灶火双色温混光;蒸汽在光中可见;人物侧影背对门,轮廓光勾勒肩线。
- **镜头**:门外窥视机位(门框压暗,室内光从门缝漏出,人物剪影在光区——观众与窥视者同视角)。
- **剧作功能**:EP2 凉子深夜热牛奶+小狗蹲守门口——静场情感传递,不靠台词靠光与蒸汽。
- **🎬 提示词**:`...深夜厨房:和纸小夜灯与灶火双色温,陶壶蒸汽缓缓升起又消散。女性侧影背对门,轮廓被侧逆光勾勒,双手捧冒热气陶杯。门外机位门框压暗,室内光从门缝漏出。镜头缓慢推近,蒸汽运动与人物动作错峰,光源位置不变。`

## 6. 風呂場(浴室+脱衣所)｜蒸汽场

- **空间锁定**:脱衣所(木地板、收纳筐)→ 浴室(瓷砖、扁柏木浴桶、铜镜)。两段式动线。热水后铜镜全白起雾,**蒸汽=天然遮挡层+情绪滤镜,近浓远淡表达空间深度**。
- **镜头**:门缝先开(预备)→ 蒸汽弧线翻滚涌出→人物裹浴巾冲出(跟随),湿发甩水(次要动作)。**浴巾+蒸汽双重遮挡**,身形只露肩部以上(合规且自然)。
- **剧作功能**:EP2 变身"湿"条件触发点;喜剧+身份隐瞒双戏。
- **🎬 提示词**:`...扁柏木大浴桶盛满热水,白色蒸汽从门内涌出充满画面,铜镜被白雾覆盖。人物轮廓穿过蒸汽呈朦胧剪影,湿发甩出水珠。门先开一条缝,蒸汽沿弧线翻滚涌出,随后人物裹浴巾快步冲出,浴巾与蒸汽双重遮挡,只露肩部以上。镜头:门外中景固定,单镜头,蒸汽近浓远淡。`

## 7. 屋外:家门前・沿海石板街道｜外景过渡

- **空间锁定**:碎石石板空地(接缝海盐白痕)→ 海风定型灌木(朝一侧倾斜)→ 临海街道 → 远处海面。**朝向逻辑:家→街→海,海风方向=视觉动线。**
- **画面特征**:傍晚夕阳低角度斜射,石板拉长人影,海面碎金;暖橙天 vs 冷蓝阴影(黄昏互补色);海面薄雾。
- **镜头**:大远景(家+街+海同框建立地理)→ 中景侧光跟随脚步→ 推门入内(衔接场景 1)。
- **剧作功能**:呼吸段 + "海=小镇身份"视觉母题(呼应花穗旧照片)。
- **🎬 提示词**:`...傍晚沿海小镇街道:碎石石板路泛暖橙夕阳,海风先吹低矮灌木再传向衣摆发丝,远处海面碎金波光。人物沿石板路走向日式民宅,影子拉长朝同一方向。色调:暖橙天空与冷蓝阴影对比。镜头:大远景缓慢横移后固定中景跟随脚步,单镜头,夕阳方向恒定。`

## 结构要点回顾

- 每场都有**空间锚点**一句话(全屋地理关系网:台阶分界/桌下空间/门缝光带/走廊唯一通道)
- 动态全部翻译成**可观察动画语言**(预备→弧线→跟随→错峰),不写原则名
- 每场带**声音层**,深夜戏放大木质回响
- 提示词统一带 `anime style, cel shading` 风格标记 + "保持 X 不变"清单 + 单镜头
- 遮挡用**场景内自然元素**(浴巾/蒸汽/门框/逆光),不靠防雷词
