# 视听转译要点（Abstract → Audiovisual Translation）

> 来源：剧本转 AI 视频分镜方法论增量提取（2026-08 融合）
> 用途：把抽象文学语言转译为"摄影机能拍/麦克风能录"的具体视听语言，供分镜与 AI 视频提示词使用
> 触发：S2 分镜时遇到抽象描述、AI 视频提示词编译前
> 定位：**方法参考，不是新格式**——分镜格式权威仍是 storyboard-script-spec，Shot Contract 仍是 ai-2d 协议

## 核心铁律

1. **抽象描述必须转译**："他内心崩溃了" → "茶碗在他手里出现压痕"。**不允许任何抽象/文学/心理描写直接进入分镜或提示词**
2. **镜头服务剧本与情绪，不为构图押韵而押韵**：每个镜头的取值（焦段/光圈/机位/构图/运镜）必须能回答"为什么这么拍"
3. **每镜必须服务情绪锚点**：每个分镜必须能映射到情绪节拍，映射不上 = 镜头无效。禁止为切而切
4. **双视角对齐（内部思考，不输出）**：演员视角 + 观众视角必须对齐再输出，思考过程不写进交付物
5. **真实反馈，不捧杀**：剧本的戏剧动作不清楚就直说"这场戏镜头落不下去，问题在剧本结构"，不硬拍

## 转译四步

```
① 提取抽象元素：心理描写 / 情绪形容 / 比喻句
② 找具象载体：什么动作/物件/环境声能外化这个状态？
③ 选可拍动作：镜头能看到的动作链（蓄势→接触→冲击→结果）
④ 补视听细节：光线/声音/道具磨损/环境反应
```

### 转译对照示例

| 抽象描述 | 可拍画面 |
|---|---|
| 他内心崩溃了 | 茶碗在他手里出现压痕 |
| 她意识到被骗 | 反复拨打那个号码，直到语音提示已注销 |
| 他很紧张 | 指甲划过桌面划痕，发出细微声响 |
| 气氛很压抑 | 光束里的灰尘剧烈跳动 |

## 衔接五维度（段内）

```
轴线 / 视线 / 动作 / 物件 / 景别跳跃
衔接错乱 = 观众出戏
```

## 运镜衔接五模式

```
同向 / 反向 / 静切动 / 动切静 / 同质叠加
不允许一段戏内运镜方式过多导致风格混乱
```

## 构图雷区（主动规避）

```
断关节 / 头顶贴边 / 视线无空间 / 物体穿身 / 微距主体不明
```

## 对 AI 视频模型的口径（与现有 H3/Seedance 流程对齐）

- 运镜中文歧义时加英文（避免模型识别错误）；无歧义不加，避免冗余
- 参考图映射：环境=@图1，角色=@图2、@图3…，写入会话参考图档案
- 质量后缀：根据剧本类型/节奏/平台反推，不预设固定档位
- **分段时长以目标引擎为准**：H3 10-15s / Seedance 2.5 30s 组 / 其他按引擎契约——不套用固定 15s

## 与现有 skill 的边界

| 相关 skill | 边界 |
|---|---|
| `storyboard-script-spec` | 格式/空间/时长权威；本 Pass 只提供转译方法与衔接检查 |
| `导演思维` | 本文件即挂载于导演思维 references，作为其转译工具 |
| ai-2d Shot Contract / Adjacency | 本 Pass 的衔接五维与 ai-2d 五锁同源，输出直接进 Shot Package |
| `王叔微表情提示词` | 表演层补充：转译后的动作由 FACS 码细化 |

## 与 V4.0 系统的挂接

- 产出落点：S2 Shot Package（转译后的可拍动作行）
- 触发路由：S2 分镜编译前自动叠加
- 校验：分镜/提示词中出现抽象心理词 = FAIL（回本 Pass 转译）
