# Story Craft for H3 — 故事层 QA（解决"剧情跳/情绪跳/分镜跳"）

> 触发场景：用户反馈"故事很跳""情绪对不上""角色行为没理由""分镜跳脱"。
> 来源：ai-2d-animation v1.5 的 story-craft / shot-adjacency 方法论，压缩为本 skill 适用的可执行检查。
> 核心原则：**镜头语言补不了故事因果**——先修故事层，再修镜头层，最后才修 Prompt 措辞。

## 1. 关系前史（开场 3 镜内必须传达）

观众必须在前 3 个镜头内知道**角色之间是什么关系**，否则后续亲密/冲突/反应全被误读。

| 关系类型 | 开场线索示例（一个镜头量） |
|---|---|
| 旧情人/久别重逢 | 她指尖抚过旧痕、看旧照、无意识喊出他名字的音节 |
| 恋人 | 共同物品（戒指/钥匙/照片）、只有彼此懂的动作 |
| 暗恋未明 | 她排练"遇见他"的对话、对着镜子练习表情 |
| 敌对/压迫 | 第一次对视的敌意、对抗站位 |
| 陌生人初遇 | 第一次视线接触的迟疑 |

- 线索必须**可被单帧读到**（道具/称呼/动作/微表情），不能只在台词背景里。
- 开场是"角色独处"时（如舞蹈室/深夜房间），线索放**无意识动作**或**环境道具**上。

## 2. 情绪阶梯（禁止跳级）

情绪变化必须走阶梯，禁止 A 直接跳到 C。

```
觉察 → 犹豫 → 软化 → 默许 → 情动 → 失控 → 余韵
（或）惊讶 → 怀疑 → 理解 → 接受 → 投入 → 爆发 → 平静
```

每个跳级点必须有**过渡节拍**（至少一个镜头或一个表演节拍）：
| 过渡 | 节拍内容 | 例子 |
|---|---|---|
| 觉察→犹豫 | 动作中断、手抬起又停住 | 她手抬起想推他，停在他胸口 |
| 犹豫→软化 | 一句唤起记忆的台词/细节 | "你跳这支舞，和五年前一样" |
| 软化→默许 | 眼神接触=默许信号（必须先于身体接触） | 她抬眼看他，他才动手 |
| 默许→情动 | 呼吸变化、身体前倾、闭眼 | 她仰头轻喘、抓他手臂 |

硬规则：
- **身体接触必须晚于默许信号**（对视/放松/不再推拒）——禁止"角色还没同意，手已经摸上去了"。
- 指不出过渡节拍 = 跳级，必须补节拍。
- **15s 内最多 3 级情绪变化**（如 觉察→软化→情动），4 级以上必然跳。

## 3. 因果链（每个 Beat 四问）

1. 为什么现在发生？（时间触发器）
2. 角色为什么这么做？（动机：可被前史+关系解释）
3. 为什么是这种方式？（性格）
4. 之后会怎样？（后果：必须改变下一拍状态）

断链信号：行为只能由"剧情需要"解释、情绪与关系前史不符、镜头只有时间先后无因果。

## 4. 信息释放表（什么信息、何时、给谁）

| 信息 | 观众知道于 | 角色知道于 | 释放手法 |
|---|---|---|---|
| 关系前史 | 镜 2（线索镜） | 双方已知 | 道具/动作暗示 |
| 他来了 | 镜 2 | 她镜 5 才发现 | 镜面倒影 |
| 她的情感 | 镜 4 | 他看懂了 | 无意识喊名 |
| 他的情感 | 镜 7 | 她镜 7 | 台词/记忆 |

- 观众知道的 ≥ 至少一个角色知道——信息差是张力来源。
- 每个 WITHHOLD 必须有对应 REVEAL 时刻，不许悬空。
- **15s 内信息点 ≤3**；超过优先删除/合并，不加镜头。

## 5. 相邻镜头连续性（分镜"跳脱"诊断）

"分镜跳脱"通常不是单个镜头不好，而是相邻镜头之间没有桥。

- **30/70 原则**：相邻镜头默认 70% 状态继承、30% 信息变化；超过 3 个关键变量变化必须标记 HARD_CHANGE 并加桥接。
- **连续锚点**：相邻镜头至少共享 3 个（人物身份/空间锚点/屏幕方向/视线/道具/光向/动作状态）。
- **视线与动作匹配**：看向画外 → 下镜给被看对象（除非故意 WITHHOLD）；手抬起 → 下镜不能突然已完成动作；向右运动 → 下镜默认继续向右。
- **Re-establish**：连续 3 个以上近景后，若空间关系是剧情必需，插入空间建立镜头。
- **空间桥**：室内↔室外 / 左↔右反转 / 站立↔坐下 / 新角色突现，必须有 movement/gaze/sound/object/中性镜桥接。
- 每对相邻镜头问：角色在哪？他刚才做了什么？为什么现在做？方向变没变？这个 Cut 带来什么新信息？——任一连续两问答不上 = ADJACENCY_RISK。

## 6. 场景（Scene）必须"变"

每场戏是完整戏剧单元，不是地点标签：`Goal → Conflict → Tactic → Complication → Turn → Exit State`。
Scene 结束必须改变至少一个：信息 / 目标 / 关系 / 空间 / 风险 / 时间压力。

## 7. 交付前 QA 清单

- [ ] 前 3 镜内有关系线索镜头？
- [ ] 每个情绪跳级点有过渡节拍支撑？
- [ ] 每个 Beat 能回答"为什么现在/为什么这么做/为什么这样/然后呢"？
- [ ] 角色行为能被动机解释，而非仅剧情需要？
- [ ] 每个 WITHHOLD 有对应 REVEAL？
- [ ] 15s 内信息点 ≤3、情绪级 ≤3？
- [ ] 亲密/冲突行为晚于默许/触发信号？
- [ ] 相邻镜头共享 ≥3 个连续性锚点？
- [ ] 场景切换有空间/时间桥，无 SCENE_TELEPORT？
- [ ] 伏笔有 Payoff（seed → reinforcement → payoff）？

## 失败优先级

用户说"跳"时，修复顺序固定：`Story Causality → Scene Geography → Shot Adjacency → Camera → Prompt`。
**不得直接从 Prompt 措辞层修补剧情问题**——先检查故事层。
