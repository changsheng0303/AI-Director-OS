# Storyboard → H3 多段提示词（EP1 实战方法）

> 来源：2026-08《海风女子学园 EP1》35 镜分镜 → 15 段 H3 的实战经验。

## 何时用
- 用户给 EP 级长分镜（30+ 镜，总时长 2-3 分钟）要求整集提示词
- 分镜含大量短镜（0.3s 闪切/字幕/转场镜）

## 分段方法
1. **按场景/叙事单元合并连续分镜**，每段 ≤15s（H3 单段上限）；一段 = 一个空间 + 一个动作单元，空间跳变处拆段。
2. **纯字幕镜（"5小时前"/片尾字幕）、纯特效镜（倒放/闪切/过曝）、纯转场镜 → 不写进提示词，留给后期剪辑**（H3 做字幕/倒放不可靠）。分镜表里标注"后期补做"。
3. **每段 ≤4 张参考图**（全图保真 v2 规则，见 multi-reference-fidelity.md）：1 角色主图 + 1 场景图 + 1 道具/服装 + 必要时第 2 角色。超了继续拆段。
4. **台词逐字保留**：`<d>[Chinese] 原话</d>`；画外音用稳定 (S1)/(S2) ID；分镜里的心理描写/叙事目的不写进提示词（画面可见才写）。
5. **每段独立六段式**，detailed_description 首句带风格锚：`style-anime-lineless: no outlines, cel-shaded flat coloring, hard-edged cel shadows, streak hair highlights, clean smooth texture`。
6. **逐段校验**：`validate_ref2va_prompt.py <file> --duration <N>`，切点必须 < 时长（15s 段最后一个切点 ≤14.5s）。
7. 交付物 = 分段总览表（段号/分镜范围/时长/参考图清单）+ 每段一个 .txt + 参考图清单（已有✅/需生成❌ 分类，附生成依据）。

## 陷阱
- **视觉母题跨段不连续**（心率 98→112→135→150、蒸汽意象）：模型无跨段记忆，每段必须独立描述当前值/状态，不要写"同上段"。
- **分镜的"0.3s 闪切/倒放/字幕"直接写进提示词会翻车** → 后期补，提示词只写可生成的连续动作。
- **一段多角色同框**：全部点名还原（全图保真 v2），用"全景句同时点名多图"或拆镜聚焦，禁止把配角降级成模糊背景。
- **多角色每段 5 图 → 必然漂移**：5 图段必须拆成 2 段（3图+2图），这是硬规则不是建议。
- 参考图用户可能只按类型给（"角色/场景"）不点名对应 → 用文件名+历史资产推断，推断不了反问（见 multi-reference-fidelity 第四章）。
