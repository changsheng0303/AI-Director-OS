# 短分镜（2-5s）多节拍压缩 & 直接生成偏好

2026-08-19 实测：《海风女子学园》EP1 分镜 13-1「被挤出教室」4 秒段。

## 场景：用户给了什么

用户贴出的分镜描述常含 **5+ 个精确时间节拍**（本例：铃响 0-0.6s → 夹人群 0.6-1.4s → 被挤到前 1.4-2.5s → 挤出 2.5-3.5s → 踉跄+遮挡转场 3.5-4.0s），但 H3 短分镜**物理上限 2-3 镜**（每镜 ≥1s，切点过密会崩）。

## 压缩策略（本次验证通过）

1. **同机位连续事件合并为单镜长描述**：镜内用 `first / next / then / finally` 串多个节拍，不切镜
2. **切点只设在动作链断点**：4s 实测用 0 / 00:01.400 / 00:03.000 三镜——第 1 镜建立空间与事件起点，第 2 镜中段位移链，第 3 镜高潮+收尾转场（末镜 <1s 的转场遮挡可行）
3. **固定机位喜剧段整体压 1-2 镜最稳**：笑点靠"相对位置变化/人群压力"而非切镜，切点过密（<2s/镜）反而崩
4. **转场遮挡放末镜收尾**：如"白色制服全屏遮挡"接下一段，写 `covering the screen completely to carry into the next shot`

## 校验结果参考

- 格式校验 `validate_ref2va_prompt.py --duration 4`：PASS 0 errors
- 词数 `check_description_words.py`：524 词（350-500 达标）
- 3 镜 4s 的切点写法：`[Shot 1]`（无时间戳）→ `[Shot 2] At 00:01.400,` → `[Shot 3] At 00:03.000,`

## 用户偏好：直接生成

用户中途发「直接生成提示词」打断追问（out-of-band）——教训：

- **用户贴超详细分镜文字（含精确时间轴）= 信息足够，直接写六段式交付**
- 不要先追问"要不要参考图 / 改时长 / 确认场景"
- 场景无参考图 → 纯文字定义：`<Subject N> is the [场景], drawn in 2D anime background art style, featuring...`
- 角色有已认可参考图 → 绑 `<Picture N>`（如男主图）
- 交付时参考图清单表标注 `❌ 无图（如需可生成）`，用户自行决定是否补图
- 追问只在关键信息**真正**缺失时做（角色名都对不上 / 分级不明）
