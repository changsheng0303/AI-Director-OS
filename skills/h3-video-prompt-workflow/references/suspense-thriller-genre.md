# 悬疑/惊悚类视频提示词（用户校准 2026-08）

> 适用：用户给悬疑/惊悚题材（含参考图：儿童躲藏窥视、深夜异响、未知威胁画外）时写视频提示词。
> **用户校准（本会话实测）**：第一版提示词按参考图分析写成"动作极少、极慢推近"（眼神微动+手指收紧），用户明确纠正：**"动态大一些"**——悬疑≠静止，必须有连续动作链（惊醒坐起→爬行→躲藏→钻床底→门把手→光束逼近→僵住）。不要把"克制"写成"没动作"。

## 悬疑提示词的结构骨架

1. **"反应先于原因"构图**：参考图只给人物反应（惊恐的双眼+搭在遮挡物边缘的手指），威胁永远画外——不要生成怪物/凶手的正面画面，观众脑补的恐惧>直给。
2. **三段式时间轴**（10s 版）：
   - 0-3s 屏息窥视（眼神缓慢扫视、几乎无动作）
   - 3-6s 收紧（手指攥紧遮挡物边缘、镜头开始极慢推近、呼吸屏住）
   - 6-8.5s 逼近（远处光源微闪、眼神骤停锁定画外）
   - 8.5-10s 急转（眼神猛转向画面右侧、手指更紧、推近加速、停在眼睛特写）
3. **动态大版本的动作链模板**（用户偏好的量级）：
   - 惊醒猛坐起 → 手电光束乱晃 → 爬下床蹲伏移动 → 探头窥视 → 听到脚步声缩回 → 快速爬向床底 → 钻入捂住嘴 → 床底视角（皮鞋/门把手/门缝光） → 光束扫向床底 → 门外呼唤 → 正要爬出 → 第二次异响 → 僵住瞳孔骤缩
4. **Ending Function 用 SUSPENSE_HOLD**：结尾停在"威胁仍画外+人物定格恐惧"，悬念交给下一镜；ending_reason 写"危险保持画外是本场戏叙事机制（Scene Archetype=SUSPENSE），下一镜揭示目标"。
5. **参考图关键参数要锁定进 LOCKED STATE**：前景虚化遮挡物（低机位窥视感）、暖侧光左亮右暗、眼睛矩形高光、浅景深焦点锁双眼、低饱和黑棕色调、胶片颗粒。

## 微动作清单（悬疑专用，替代"很害怕"类空词）

- 眼神：缓慢扫视→骤停锁定→瞳孔骤缩→单次慢眨眼
- 手：指尖轻搭→攥紧边缘→指节发白→捂嘴
- 呼吸：屏住→急促→屏住
- 光束/光影：远处光源微闪、门缝光线扩大、手电光束扫动

## 负面提示词（悬疑必带）

```
jump scare, monster appearing, gore, violence, screaming, crying,
fast head turns, camera shake, bright daylight, vivid colors,
full body visible, clear background, cartoon style, anime style,
deformed fingers, extra limbs, mismatched eyes, subtitle, watermark
```

## 分级注意

悬疑/惊悚属 L0（SFW），儿童角色在悬疑剧中是正常影视内容（如《寂静之地》式镜头），不涉性即可。分级只管成人内容边界，不管镜头语言——特写/慢镜/推近在悬疑片里正常使用。
