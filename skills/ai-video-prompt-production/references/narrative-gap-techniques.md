# 信息差镜头语言（Narrative Camera Logic）— 高张力 / L3 场景用法

2026-08 实测于《雨夜·倒影》（错过戏）与《镜间》（L3 舞蹈室）两条 15s H3 提示词。核心：**张力不靠裸露/动作堆砌，靠"观众知道 > 角色知道"的认知差**——普通观众说不出术语，但会替角色着急，这就是镜头语言在起作用。

## 与 ai-2d-animation 的衔接

ai-2d-animation §11 Gate 1 + references/story-craft.md 是规则源；本文件是**已实测的 prompt 写法速查**。

## 核心结构（Camera Logic 链）

```
ESTABLISH（空间+关系）→ WITHHOLD（藏信息）→ ALIGN（对齐观众视角）
→ ESCALATE（加压）→ REVEAL（揭示）→ MISDIRECT（误导反转）→ RELEASE（释放）
```

规则：
- 观众知道的 ≥ 至少一个角色知道——信息差是张力来源
- 每个 WITHHOLD 必须有对应 REVEAL 时刻，不许悬空
- 15s 内信息点 ≤3，情绪级 ≤3（story-craft 硬规则）

## 三个已实测的母题结构

### 1. "观众先看到，角色后知"（错过戏）
《雨夜·倒影》8 镜：观众镜 2 就看到他 → 之后 4 镜观众都在"替她着急" → 镜 5 她发现（MISDIRECT：观众以为要进门，结果转身走了）。
- 写法要点：镜面/玻璃/倒影是天然的信息分层道具（反射=两个世界）
- 视觉母题例：玻璃倒影同框永不接触；唇印淡去=存在过的证据正在消失

### 2. "被凝视的心理张力"（L3 成人向）
《镜间》8 镜：她以为独处，他从镜中看——前 5 镜全是无意识展示（弯腰/旋转/衬衫滑落），观众知道他看着。发现瞬间（瞳孔收缩+动作冻结）是全部积累的引爆点。
- 对 L3 的意义：同样的尺度，多一层"看与被看"的心理层，比直接挑逗高级
- 写法要点：关系线索放她的**无意识动作**（触旧痕/喊名字音节）；他先以剪影/倒影出场
- 亲密/冲突行为必须晚于默许信号（对视/放松/不再推拒）——story-craft 硬规则，L3 同样适用

### 3. "静→爆→静"节奏落差（战斗/高燃）
《雪夜一刀》8 镜：80% 时间蓄力（长镜/留白/微动），20% 爆发（冲击帧），5.5s 慢镜余波。
- 雪是时间标尺：悬停（冻结）→ 切分（速度）→ 慢飘（恢复），同一元素三种时间语义
- 冲击音精确落在白闪那一帧（声画咬合）；拔刀前全静音

## 交付时的呈现

多镜提示词交付说明里点出信息差设计，用户能感知镜头语言存在：
- "观众先看到他 → 她发现"（信息差）
- "镜 5 的瞳孔收缩是全部积累的引爆点"（情绪阶梯）
- "前 5 镜她不知道，观众知道的越多越急"（WITHHOLD）

## 与 shots-library（94 setup）配合

- 错过/揭示戏：Freeze Reveal → Background Reveal → Mirror Talk
- 亲密/暧昧：Eye Contact → Push to Talk → Close Faces → Object Hinge
- 张力升级：Closing Space → Claustrophobic Space → Push On Nothing
- 高燃战斗：Long Lens Stunt → Matching Motion → Cutting For Impact
