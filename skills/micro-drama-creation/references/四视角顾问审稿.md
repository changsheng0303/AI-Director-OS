# 四视角顾问审稿（Four-Perspective Advisory Review）

> 来源：剧本创作方法论增量提取（2026-08 融合）
> 用途：大纲/剧本定稿前，由四种行业身份独立评估
> 触发：S1.5 审稿 / 用户要求"审一下大纲/多视角评估"
> 铁律：**四个视角全部独立给出，不可省略；每视角至少 2 个真实问题**——某视角找不到问题 = 评估深度不够，重新评估

## 四视角定义

```
【编剧视角】审故事结构与角色逻辑
【制片视角】审市场与制作可行性
【观众视角】审情感共鸣与代入感
【平台视角】审审核风险与平台调性
```

## 输出结构（四视角全部独立）

```markdown
【编剧视角】
评估：____
两个核心问题：① ____ ② ____
建议改法：____

【制片视角】
评估：____
两个核心问题：① ____ ② ____
建议改法：____

【观众视角】
评估：____
两个核心问题：① ____ ② ____
建议改法：____

【平台视角】
评估：____
两个核心问题：① ____ ② ____
建议改法：____
```

四视角输出后，整理**修改建议清单**按影响优先级排序：

```markdown
建议1（必改）：____
建议2（必改）：____
建议3（建议改）：____
建议4（可选）：____
建议5（可选）：____
```

## 处理规则

1. 请用户选择采纳哪些建议（可全选/部分/全不选）
2. 基于选择更新大纲/剧本，给出更新版
3. 对更新版仍不满 → 可重复审稿**最多 2 次**
4. 重复审稿必须**切换关注维度**（第1次主审结构+角色，第2次主审节奏+主题+平台调性），避免重复批评
5. **反捧杀**：审稿环节绝不能滑向"四视角都说好"
6. 已激活对标 DNA 时：每视角至少引用 1 条 DNA 规律作为评估锚点

## 与现有 skill 的边界

| 相关 skill | 边界 |
|---|---|
| `红果审剧本`（screenwriter-skill） | 红果=内容负责人单一权威视角（市场/钩子/生死线）；本 Pass=四身份独立评估。两者可叠加：先四视角出全貌，再红果出平台向定论 |
| `剧本医生·圆桌会诊`（未安装） | 圆桌=4-6评委轮替；本 Pass=固定四视角。若后续安装圆桌，本 Pass 作为其轻量版 |
| ai-2d Gate1 Story QA | 本 Pass 输出进入 Creative Audit Package，Gate 判定仍由总控执行 |

## 与 V4.0 系统的挂接

- 产出落点：S1.5 Creative Audit Package → `advisory_review: {perspectives, priority_fixes, adopted_by_user}`
- 触发路由：S1 大纲锁定前 / S1.5 审核时叠加
- 校验：四视角任一缺失或某视角无 2 个问题 = FAIL 打回
