# 对标作品 DNA 提取（Benchmark DNA Extraction）

> 来源：剧本创作方法论增量提取（2026-08 融合）
> 用途：用户点名对标作品时，提取其创作规律作为本次创作的隐性约束，写入 Story Contract 的 `reference_dna` 字段
> 触发：用户提到"对标《XX》"/"风格类似《XX》"/"激活对标DNA《XX》"

## 铁律

1. **宁少勿多**：列出 5-7 条规律，不必凑数
2. **每条必须给观察依据**：哪个场景/哪段对白/哪个镜头
3. **每条必须标置信度**：高/中/低
4. **诚实底线**：对该作品训练数据极少（冷门/新作/地区作品）时**禁止装懂**，直接说"我对《XX》了解有限，请提供 3-5 条关键特征"，严禁编造规律
5. **用户确认后成为隐性约束**：后续所有产出必须参照，创作笔记中引用规律编号
6. **不主动以公司/作者名做身份背书**：不说"参与过《XX》"，只描述"擅长该类型节奏"

## 七个分析维度（按需选 5-7 个最显著的）

```
① 结构特点：三幕比例、节拍分布
② 节奏特点：开场速度、转折密度、留白处理
③ 对白风格：信息密度、口语化程度、人物语言区分度
④ 视觉/镜头偏好：构图、运镜、色彩、光线倾向
⑤ 主题倾向：重复母题、情感落点、价值观底色
⑥ 标志性元素：反复出现的视觉/听觉/叙事符号
⑦ 禁忌或反例：该作品从不做的事情（同样重要）
```

## 输出格式

```markdown
《[作品名]》创作 DNA 提取
──────────────────────────────
规律 1：[一句话概括]  【置信度：高】
   观察依据：____
   对本次创作的指导意义：____

规律 2：[一句话概括]  【置信度：中】
   观察依据：____
   对本次创作的指导意义：____

（共 N 条，N ∈ [5, 7]）

请审视：保留哪几条？修改哪几条？哪几条不适用？补充哪几条？
```

## 与现有 skill 的边界

| 相关 skill | 边界 |
|---|---|
| `cinema-dna-21x9x3` | 那是镜头/构图方法论；DNA 提取是故事/风格/节奏规律，两者不冲突，可叠加 |
| `graded-anime-plot-writing` | 那是分级剧情写法；DNA 提取是任意作品的规律分析，分级项目可叠加 |
| ai-2d-animation Story Contract | DNA 规律写入 `reference_dna` 字段，不替代 Story Contract 结构 |

## 与 V4.0 系统的挂接

- 产出落点：Story Package → `reference_dna: [{works, rule, confidence, evidence, guidance}]`
- 触发路由：S1 创作时用户点名对标 → 总控路由到本 Pass
- 校验：每条规律必须有 evidence + confidence，缺则 QA 打回
