# Generation Spot-check — Universal Dialogue Core v2.1

> 单模型、自生成、自评的快速回归检查；**不是独立 Blind A/B**。用途是确认新规则没有明显破坏自然度、比例控制和可演性。

## S01 — FUNCTIONAL / 任务交接

**条件**：同事把钥匙交给值夜班的人。无秘密、无冲突。

**对白**

甲：（把钥匙放桌上）后门这把有点涩，往里顶一下再拧。

乙：知道了。报警器还是十一点自动开？

甲：嗯。今天不用手动碰它。

乙：行，你走吧。

**检查**：没有强加潜台词或情绪戏；任务完成即结束。

**Self-score**：96/100（按 Light Gate）。

## S02 — Concealment + Listener Model

**条件**：林知道自己弄坏了杯子；周只看到地上有水。林误以为周已经看到碎片。

周：地上怎么湿了？

林：（先看了一眼垃圾桶）我收过了。

周：我问的是水。

林：……洗杯子的时候洒的。

周：哪个杯子？

林：你不是都看见了吗？

周：（看向垃圾桶）我现在看见了。

**检查**：林的失误来自“以为对方已知”，不是客观知识泄漏；周最后才获得新信息。

**Self-score**：95/100。

## S03 — Interrogation Bluff

**条件**：老师不知道是谁改了名单，只知道小陈最后离开教室；老师故意表现得像掌握更多信息。

老师：名单改过以后，你还回过讲台，对吧？

小陈：谁说我回去了？

老师：我没说有人看见。

小陈：……我只是拿水杯。

老师：水杯放哪边？

小陈：窗边。

老师：名单在另一边。

小陈：所以呢？

老师：所以我现在只知道，你比刚才多告诉了我一件事。

**检查**：bluff 不被当作真实证据；每轮缩小未知。

**Self-score**：94/100。

## S04 — Conflict / Turn Coupling

**条件**：A 要取消计划，B 认为 A 又在临时逃避；两人都克制。

A：明天我不去了。

B：这次是哪一种“不去”？

A：你可以直接问原因。

B：上次我问了，你说“没事”。

A：所以你现在打算替我回答？

B：我在问，你这次会不会回答。

A：（停顿）家里有事。细节我现在不想说。

B：好。那我只确认一件——不是你临时反悔。

A：不是。

**检查**：每句都在接上一句的行为，不是轮流发表立场；冲突通过定义权和边界推进。

**Self-score**：95/100。

## S05 — Load Transition: INTERACTIVE → DRAMATIC

**条件**：兄妹整理旧箱子，起初只是日常互动；妹妹突然发现一封本不该存在的信。

妹：这盒磁带你还要？

哥：你要是能找到播放器，我就承认它们有用。

妹：那我扔了。

哥：你敢。

妹：（从盒底抽出信封）……这是谁写给爸的？

哥：给我。

妹：你认识？

哥：先给我。

妹：你刚才还不知道盒子里有什么。

哥：（伸出的手停住）我知道这封信。

**检查**：前半不提前戏剧化；触发物出现后才提高负荷。

**Self-score**：94/100。

## S06 — Function Phase: Concealment → Conflict

**条件**：A 一直隐瞒自己替 B 做了决定；B 找到明确证据后，场景机制从隐瞒变成边界冲突。

B：申请是你撤的？

A：现在说这个没意义。

B：我问是不是你。

A：我只是觉得那个机会不适合你。

B：（把邮件打印件放桌上）所以是你。

A：……是。

B：你凭什么替我决定？

A：因为你那时候根本没看清——

B：我看没看清，是我的事。

A：你会后悔。

B：那也该是我后悔。

**检查**：证据是 transition trigger；前半 concealment，后半核心变为 decision boundary conflict。

**Self-score**：94/100。

## S07 — Group Dialogue / Attention Pivot

**条件**：四人讨论谁忘了锁门。阿宁一直没说话，但把备用钥匙放到桌上，改变全场注意力。

乔：昨晚最后走的是小麦。

麦：我走的时候门是关的。

岑：关上和锁上不是一回事。

麦：那你怎么不问乔？他后来又回来拿过外套。

乔：我没进门。

（阿宁把备用钥匙放到桌上。）

岑：这把怎么在你这？

乔：（转向阿宁）你昨晚回来过？

阿宁：十点半。

麦：那最后一个人不是我。

阿宁：但门也不是我忘锁的。我回来时，它已经开着。

**检查**：沉默者通过动作真正改变 target / 信息 / 联盟；不是平均发言。

**Self-score**：95/100。

## S08 — Reconciliation + Exit Discipline

**条件**：A 因失约向 B 道歉；B 不准备立刻原谅，但愿意恢复有限合作。

A：昨天我答应会到。我没去，也没提前说。

B：嗯。

A：不是因为我忘了。我临时退缩了。

B：这至少比“手机没电”强。

A：我不求你现在算了。下次如果我做不到，我会提前告诉你。

B：先别说下次。

A：好。

B：（把资料推过去）今天这份，我们先做完。

**检查**：具体承认，不强迫原谅；恢复有限合作后立即结束，没有总结尾巴。

**Self-score**：96/100。
