# Hot-Blooded Anime Dialogue Adapter v1.0

## Mission

制造**竞争、决心、团队能量与逆境突破**，但避免“所有人一直喊口号”和无铺垫的燃系金句。

## Preferred Tactics

- challenge：把目标变成可回应的挑战；
- refusal_to_yield：拒绝接受对方定义的失败；
- personal_stake：把胜负连接到角色自己的理由；
- teammate_trigger：队友一句非常短的话触发行动变化；
- rivalry_push：竞争对手用最了解角色的方式刺激其突破；
- tactical_call：关键时刻用简短明确的行动语言代替长演讲；
- earned_declaration：在积累足够压力后才出现宣言；
- callback_resolve：回收此前失败、承诺或训练中的一句话。

## Beat Bias

比赛 / 战斗中：

`Pressure → Failure Signal → Reframe → Short Commitment → Action`

团队爆发：

`Fragmentation → One Clear Cue → Alignment → Execution → Reaction`

宣言场：

`Accumulated Defeat → Personal Reason → Choice → Declaration → Immediate Proof`

## Rhythm Rules

- 行动中台词必须短；
- 战术信息优先清晰而非华丽；
- 宣言之前必须有压力积累；
- 真正的高点前减少口号密度；
- 角色越疲惫，句子可越短、越破碎；
- 热血来自“说完马上做”，不是说得响亮。

## Subtext Rules

热血台词下面必须有个人理由：

- 我不想再次逃跑；
- 我要证明自己能被信任；
- 我不能让队友独自承担；
- 我需要赢回自己的选择权；
- 我承认对手很强，但不接受已经结束。

如果没有个人理由，宣言容易变成空泛口号。

## Anti-Patterns

- 每个角色都使用同一种“绝不放弃”表达；
- 连续长篇演讲打断动作；
- 没有失败和压力就突然燃起来；
- 角色只喊结果，不说自己的具体选择；
- 通过夸张形容词代替行动变化；
- 为了热血破坏战术逻辑或角色知识边界。

## Payoff Rule

宣言必须至少带来一个即时结果：

- action choice；
- tactical change；
- team alignment；
- rival response；
- emotional reversal。

只喊完口号但行动不变，判为 `EMPTY_HYPE`。

## Extra Checks

- 这句话是否只有这个角色能说？
- 说完有没有立即影响行动？
- 是否过早消耗高潮语言？
- 是否存在“低谷→选择→行动”的因果链？
