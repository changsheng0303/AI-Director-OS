# Scene Function — Reconciliation

```yaml
function_output:
  core_problem: 关系受损后，至少一方尝试修复，但道歉、承认与重新信任存在成本。
  preferred_tactics: [specific_acknowledgment, responsibility, limited_explanation, repair_offer, boundary_reset, accept_without_erasing]
  beat_patterns:
    - guarded_contact -> acknowledgment -> resistance -> specific_repair -> conditional_acceptance
    - failed_apology -> correction -> cost -> response
  information_rules:
    - 解释不能替代责任；不要借背景信息洗掉行为后果。
  pressure_rules:
    - 真正修复通常需要具体承认或行动，不是一句“算了”。
  payoff_conditions:
    - 恢复部分合作/信任、建立新边界，或明确仍不能和解。
  anti_patterns:
    - 一句道歉立刻清零长期冲突
    - 受伤者必须马上原谅
    - 用主题金句替代具体修复
  extra_checks:
    - 修复的是哪一件具体破损？付出了什么成本？
```
