# Scene Function — Conflict

```yaml
function_output:
  core_problem: 双方目标不能同时满足，语言成为争夺结果与定义权的行动。
  preferred_tactics: [deny, reframe, challenge, counterexample, boundary, pressure, withdraw]
  beat_patterns:
    - claim -> resistance -> tactic_shift -> counterpressure -> choice
    - boundary -> push -> consequence -> response
  information_rules:
    - 冲突中释放信息必须服务当前目标，不得突然变成背景说明。
  pressure_rules:
    - 每次升级都应改变策略或代价，不只提高音量。
  payoff_conditions:
    - 一方改变决定、边界、权力、关系距离或行动方向。
  anti_patterns:
    - 同一句诉求换近义词重复
    - 双方轮流发表完整立场演讲
    - 为了冲突突然降低智力或人格
  extra_checks:
    - 谁在定义问题？谁在拒绝这个定义？
    - 最后谁获得了什么，谁失去了什么？
```
