# Scene Function — Intimacy

```yaml
function_output:
  core_problem: 角色在暴露自己与保护自己之间做选择，关系距离因此改变。
  preferred_tactics: [selective_disclosure, indirect_care, test_closeness, shared_memory, boundary_offer, retreat_after_exposure]
  beat_patterns:
    - distance -> small_disclosure -> response -> risk -> boundary_shift
    - ordinary_exchange -> private_detail -> hesitation -> acceptance_or_retreat
  information_rules:
    - 私密信息的价值来自“对谁说”，不是信息本身有多轰动。
  pressure_rules:
    - 越接近真实脆弱点，越允许语言减少、停顿增加。
  payoff_conditions:
    - trust、distance、vulnerability、mutual_knowledge 或 boundary 发生变化。
  anti_patterns:
    - 用长篇自我分析代替亲密
    - 没有铺垫突然倾诉全部秘密
    - 把控制、占有或越界误写成亲密
  extra_checks:
    - 这句话为什么只愿意对这个人说？
```
