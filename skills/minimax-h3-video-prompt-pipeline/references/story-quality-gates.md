# Story Quality Gates — 叙事提示词的故事层检查（V1.5）

> 用场景：用户说"故事很跳""情绪对不上""角色行为没理由"，或外部评测指出"视觉 A 级、剧情 B 级"。
> 结论先于手段：**镜头语言补不了剧情因果**——先修故事层，再谈镜头。修复顺序：Story Causality → Scene Geography → Shot Adjacency → Camera → Prompt（严禁直接用 Prompt 层补剧情问题）。

## 1. "故事跳"四大成因诊断（先查这四条）

| 成因 | 症状 | 修复 |
|---|---|---|
| 关系前史零传达 | 亲密/冲突行为观众无法理解（"她为什么不推开？"） | 开场 3 镜内必须有关系线索镜头（道具/称呼/无意识动作/微表情），必须可单帧读到 |
| 情绪阶梯缺级 | 从 A 情绪直接到 C（冷静→崩溃/僵住→轻喘） | 每级必须有过渡节拍（犹豫/软化/默许），禁止跳级 |
| 动机缺口 | 行为只能由"剧情需要"解释 | 每个 Beat 回答四问：为什么现在/为什么他做/为什么这样做/做完改变什么 |
| 无选择 | 只有事件堆叠，高潮靠偶然 | 高潮必须来自角色选择（climax_choice），并产生可追踪的 consequence |

## 2. Story Contract 必填（15s 短片的浓缩版）

`premise / story_question / protagonist_want / protagonist_need / core_flaw_or_belief / opposition / stakes(external+internal+relational) / inciting_incident / climax_choice / consequence / relationship_arc`

- **Want 是外显目标，Need 是内隐需求，两者必须存在张力**（want=拿回画结束过去，need=承认放不下）。
- **Stakes 必须三维**（外部+内部+关系），缺一维=冲突扁平。
- **一个物件四合一**是最强杠杆：让一个道具同时承载 目标/冲突/选择/母题（例：《婚纱店》的婚纱=交付目标+归属冲突+是否承认的选择+未兑现承诺的母题）。

## 3. Beat Chain 公式（每拍必走）

`Trigger → Desire → Action → Resistance → Result → Choice/Cost → New State`

- 硬规则：`new_state[N]` 必须能解释 `trigger[N+1]`。
- 连续 Beat 只换景不换状态 = `REPETITIVE_BEAT`（事件流水账）。
- 15s 内信息点 ≤3、主要情绪跃迁 ≤3；超过就拆 Beat 或删信息，不是加镜头。

## 4. L3/成人向内容的情绪阶梯（story-craft §2 应用）

标准阶梯：`觉察 → 犹豫 → 软化 → 默许 → 情动 → 失控 → 余韵`

- **身体接触必须晚于默许信号**（对视/放松/不再推拒），"角色还没同意手就摸上去"= 跳级。
- 每个跳级点能指出"哪个节拍让它成立"；指不出=跳级，必须补节拍。
- 常用过渡节拍：犹豫=手抬起又放下；软化=一句唤起记忆的台词；默许=闭眼/没退；情动=仰头/呼吸变化。

## 5. 写作风格（用户偏好 · 硬性）

- **自然大胆**：衣料是状态不是约束——写"罗衫堆叠腰间""衣摆随动作起伏""滑入衣下"，不写"隔着布料""确保不脱衣"这类防御性措辞（用户明确拒绝过）。
- 遮挡词必须具体（"发丝垂落遮住胸线""裙摆集在腰际"），禁止模糊指令（"保持得体"）。
- **L3 三不原则**：不露生殖器/乳头必遮/臀部必遮（衣物/床单/裁切），无完全裸露；不写年龄/学生身份涉性。
- **胸部遮挡的现实逻辑（2026-09 用户纠正）**：脱外衣后上身剩内衣（bra/肚兜/运动内衣），胸部由内衣覆盖——`leaving her in only a black lace bra` 是标准写法；"长发垂落遮胸"是动画式偷懒，仅用于内衣已脱的情境。裸露的皮肤=肩/锁骨/腰/背/臂，不是胸。
- **L3 满格必须脱内衣（2026-09 用户纠正）**：L3 尺度链 = 脱外衣 → 脱内衣 → 上身完全裸露。"脱外衣剩内衣"只是 L3 前段，不是满格；满格要写 `unclasps her bra, the straps sliding down, the fabric falling away — her upper body completely bare`，乳首随后用手/发/光影/雾气遮。停在"剩内衣"= 实际只有 L2.5。
- **特定遮挡物优先于长发/手（2026-09 用户纠正）**：乳首遮挡首选按题材/角色设定的实体物件——人鱼=贝壳、古风=肚兜/抹胸、现代=蕾丝内衣、和风=和服内衬、西幻=圣光/胸甲内衬、巫女=注连绳/白布。特定遮挡物是角色设定的一部分（人鱼=贝壳是标志形象）、AI 生成更稳定、性暗示更强；长发/手/光影/雾气是兜底。遮挡要有具体脱除动作（`unties the thin cord of the seashells`），比"头发拨开"有仪式感。
- 级别未指定时默认 Level 0 并从内容推断最低合理等级；输出必须标注目标 Level。

## 5.1 L3 剧情驱动四要素（2026-09 用户纠正："重点是剧情，不是两个人站在一起"）

裸露必须是**角色达成目标的剧情手段**，不是"两个人站着→脱衣→贴住"的情境。每条 L3 生成前自检：

1. **关系**：两人是谁？（恋人/旧情/仇敌/交易/师徒/医患/人鱼×王子——必须具体，禁止"两个人"）
2. **目标**：她/他要什么？（救父/赢赌/被接纳/让他想起我/活下去）
3. **冲突**：阻力是什么？（自尊/身份/误会/不能说话/规则）
4. **反转**：临界处转折？（识破/阻止/告白/身份暴露）

外加两条硬性前提：
- **服装性暗示前提**：脱衣前的服装必须是性暗示状态（蕾丝/网袜/吊带/丝质/PVC 高开叉/旗袍开衩）。**禁止机能装**（战术背心+工装裤、运动服+长裤）——脱掉后剩运动内衣/工装，视觉上等同日常卸装，连 L1 的"健康性感展示"都不如（用户实测判定"L1 都不到"）。
- **反转位置规则**：剧情反转不能替代尺度，也不能被尺度替代。正确公式 = **尺度给足 + 反转在临界处**——先让观众看到她的牺牲/献身/暴露（脱衣推进到 L3 满格），再在临界处反转（阻止/识破/告白）。禁止"还没脱就反转"（零裸露的反转不是 L3，用户判定"L1 都不到"）。反转动作本身可以极动人：捡起落地的袍子重新披回她肩上，比直接阻止更有杀伤力。

## 5.2 题材开放机制（2026-09 用户纠正："不要订得那么死，难道没有别的题材吗"）

- **核心不是场景清单，是"裸露理由"机制**：每个 L3 场景必须回答"为什么她/他此刻必须裸露？"——裸露理由决定了裸露的合理性、情绪底色和反转方向。
- 裸露理由类型（任何题材通用）：救命疗伤 / 交易代价 / 赌约游戏 / 仪式使命 / 伪装职业 / 状态失控（化形/妖身不稳/醉酒）/ 创伤信任（疤痕）/ 诱惑狩猎 / 重逢旧情 / 禁忌边界。
- **题材 = 皮肤，机制 = 骨架**：换皮肤不换骨架就是新故事。题材完全开放——玄幻、现代、古风、西幻、和风、科幻太空、蒸汽朋克、末日、音乐舞台、体育、超能力、人外、黑帮谍战、病娇、暗黑童话（人鱼=化形裸露理由）都可。示例表只作启发，不是选项；新题材新场景随时可加。

## 6. 信息释放表

每个关键信息记录：`who_knows(观众/角色) / when_known / withheld / reveal_method / payoff_effect`

- 观众知道的 ≥ 至少一个角色知道（信息差=张力来源，例：镜中倒影先让观众看到他）。
- 每个 WITHHOLD 必须有对应 REVEAL，不许悬空。
- 伏笔遵循 `seed → reinforcement → payoff`，payoff 要制造"原来如此"。

## 7. 外部评测维度（对标用）

| 维度 | 检查 | 常见缺陷 |
|---|---|---|
| 视觉导演 | 空间锚点/母题/光影 | 场景无锚点=AI 漂移 |
| 摄影语言 | 运镜有动机 | 摄影词汇堆叠（WS→ECU→Dutch→Orbit→Whip） |
| 剧情结构 | 目标/冲突/选择/转变 | "氛围片段"≠"剧情场景" |
| 人物塑造 | want/need/flaw/arc | 开始沉默→结束沉默=无弧线 |
| AI 生成稳定性 | 动作密度/Start-End 锁定 | 15s 塞 8 个动作=必然漂移，拆原子片段 |

达标线：剧情结构 ≥9 / 人物塑造 ≥8.8 / AI 稳定性 ≥9 才算"剧情场景级"。
