# IP 世界观设定书生成（世界观先行 · 剧情后置）

用户维护多个动漫/短剧 IP（海风女子学园、爆衣味觉学园、炁渊录、高等女子学院等），本 skill 负责把 IP 的世界观与设定正式文档化。**核心理念：设定先行，剧情后置。**

## 触发与边界

- 触发：用户说"生成世界观和设定"、"写设定书"、"建世界观"、"做设定文档"。
- 边界：**本 skill 不写剧情剧本**（分集/分镜/伏笔回收是后续步骤，等用户明确要求再进入）。用户说"剧情后边再说"= 只交付设定，剧情章节全部占位。
- 设定书之后若用户说"先写第一季的线"→ 进入**季级规划**（见下节），输出独立《第一季剧情线》文档，不是逐集剧本。

## 季级规划（设定书之后的下游，2026-08 用户要求实测）

用户按多季结构做 IP（参考食戟之灵"先做一季、可能不展开"），明确要求**先只规划第一季**。产出独立文档 `{当前工作区}\剧本\<作品>_第一季剧情线v1.md`，结构：

1. **季定位**：季标题（如"鲸亭的余烬"）+ 季弧线一句话 + 季主题落点。
2. **四幕结构**：每幕列 起始-结束集数 + 幕名；每集一行 = 标题 + 事件/爆点(情绪)/钩子；集序体现 激励事件→入学/进入新世界→立足/第一次对决→季末交锋 的推进。
3. **本季出场阵容表**：角色 + 功能 + 出场集数（配角只留功能位，见角色收敛原则）。
4. **本季伏笔埋设表**：seed → 埋设位置 → 回收窗口（回收窗口标注"后续季"而非具体集）。
5. **本季爆点/爽点分布表**：集 + 类型 + 内容；节奏曲线 = 每 2 集小爆点，第 7/10/12 集大爆点，季末为季高潮。
6. **本季待补资产清单**：场景帧/设定图需求（让资产管线提前知道要生成什么）。
7. **季末钩子**：明确第二季入口（如"首席食战"），但**第二季及以后不展开**，只留一句话候选主线。

季级规划的硬规则：
- **先一季后全局**：用户明确"可能不会完全展开"→ 只写第一季细节，后续季仅留框架+季末钩子，不预设第二季集数。
- **集序必须踩用户指定的大节奏**：用户说"餐馆被夺→入学→熟悉校园/校园生活"→ 第一季就按这个顺序铺四幕，不自由发挥换序。
- **季线是文学大纲不是分镜剧本**：每集一行事件+爆点，不写逐集台词/镜头（那是微短剧创作/导演思维 skill 的下游）。

## 角色收敛原则（2026-08 用户要求实测）

- 用户明确删除过青梅竹马设定（花泽心阳/味满亭整体移除）→ **默认不加青梅/女二/多角感情线**，角色体系收敛为双主角 + 功能位配角。
- 配角只留功能位：每个配角必须回答"承担什么剧情功能"（小反派=被打脸立威 / 中反派=让主角受挫引出大反派 / 同伴=声援+喜剧+情绪后盾 / 导师=规则解说+伏笔引出）。无功能 = 不加。
- 删除设定时同步清理所有引用：角色卡/势力图/视觉锚点/资产清单（已删角色图标 ❌ 留痕，不物理删除文件）。

## 开工前必查（防重复/防冲突）

1. 先查 `{当前工作区}\剧本\` 是否已有该 IP 的产出（剧本/设定书）→ 有则读取对齐，不另起炉灶。
2. 先查 `{当前工作区}\h3-prompts\<作品>\` 资产（角色图/场景帧/提示词）→ 登记进设定书资产清单。
3. 查 session_search 历史设定（角色名、世界观关键词）→ 保持术语一致（如"衣裂体/味觉绽放/食战/焰味学园"）。
4. 有角色设定图时用 vision_analyze 核对外貌特征再写入角色卡。

## 9 章设定书结构（模板见 templates/world-settings-bible.md）

| 章 | 内容 | 必填 |
|---|---|---|
| 0 | 一句话世界观 + 作品定位卡(类型/分级/形态/风格) | ✅ |
| 1 | 世界观总纲：时代舞台/核心机制表/社会阶级结构图 | ✅ |
| 2 | 机构体系：学园/组织的概况、规则书(机制细则)、权力结构图、成员生态 | ✅ |
| 3 | 势力格局：每方立场/与主角线纠葛/内部矛盾 + ASCII 势力关系图 | ✅ |
| 4 | 角色体系：每角色 定位/外貌/服装/性格/Want/Need/核心缺陷/机制类型/视觉锚点 | ✅ |
| 5 | 故事引擎(Story Contract)：premise/question/theme/want/need/opposition/stakes | ✅ |
| 6 | 分集规划 | ⏸ 默认「剧情待定」占位 |
| 7 | 导演层设定：风格锁定/场景空间锁定表(资产即锁定)/演出规范/视觉锚点 | ✅ |
| 8 | 资产清单：路径+状态；已删项标 ❌；待补资产列清单 | ✅ |
| 9 | 分级与合规基线(L3:三不/防雷词/降级预案/学生不涉性) | ✅ |

## 用户工作流偏好（2026-08 实测，必须遵守）

1. **交付物只含设定本体**——剧情章节（分集规划/结构节点/伏笔地图）一律用「⏸ 剧情待定」占位，不预设具体分集、不写集数大纲。
2. **"剧情后边再说" = 立即删除已产出的剧情剧本文件**（用户明确要求过删除 EP01），保留设定书与资产；不要劝留、不要软删除。
3. **伏笔只留"候选池"**：列出 seed 素材（道具/台词/关系线索），注明"剧情确认后再做 seed→payoff 绑定"，不绑定具体集数。
4. **资产登记强制**：角色图/场景帧/H3 提示词路径全部入表，防止后续重复生成；删除的剧本也要在清单里标注 ❌ 留痕。
5. **核心机制叙事武器化**：给世界观的核心机制内置一个"可作破局点"的变体（例：《爆衣味觉学园》衣裂的「伪绽放」=裂一半=理事会作弊工具，是第二季识破暗箱的伏笔）。福利机制不只是福利，要能推动剧情。
6. **导演层设定同步输出**：场景空间锁定（已有场景资产直接锚定用途）、镜头语法规范（衣裂演出七条：直面原则/景别递进/Murch 情感切点/三区遮挡/尺度先于剧情/节拍图/5s 快剪压缩）、角色视觉锚点——给后续分镜与 H3 提示词留硬约束。
7. 版本号管理：用户要求改结构时升版本号（v1.0→v1.1）并在头部记录变更原因。

## 分级合规基线（成人向 IP 必带）

- L3 三不铁律：生殖器/乳头/臀部永不露出；遮挡手法（构图/手/光影/道具/雾气/背对）必需。
- 防雷词（L3 强制）：nipple/breast/bare/naked/nude/sex 等不出现在 Prompt 文本。
- 学生角色不涉性；降级预案：平台受限 L3→L2（衣料爆裂、半脱挂肩、内衣保留），世界观结构不变。

## 设定现代化迭代（2026-08 实测）

用户可能要求整体改环境设定（例：《爆衣味觉学园》从传统街头摊位 → 现代街角小饭馆）。这是**全局同步操作**，不是单点修改：

- **同步面**：设定书（一句话世界观/势力/角色卡/场景锁定表/资产清单）+ 第一季剧情线 + 已写逐集剧本 + 已编译 H3 提示词包（英文环境词）。漏一处 = 世界观与画面冲突。
- **中文批量替换**：先长词后短词（"鲸亭摊前街道"→"鲸亭饭馆门前" 优先于 "摊位"→"饭馆"），替换后 grep 残留关键词（"摊"）复查，不能只看替换计数。
- **英文 H3 批量替换**：同样先长词后短词（`street food stall`→`small restaurant` 优先于 `stall`）；替换后**必须语义复查**——批量替换会产生三坑：① 动词不配（`lifts the glass door` 玻璃门不是掀的 → 改 `slides open`）② 重复词（`worn worn indoor slippers`、`warm orange warm street sign lights`）③ 残留词（`small street stall` 因 `street food stall` 规则未命中而漏网）。复查 = grep 残留关键词（stall/awning/slabs/clogs/noren）+ 重跑 ref2va 校验器 + 抽查关键动作句。
- **保留合理的和风元素**：现代日本语境下居酒屋 noren 暖帘、老板娘浴衣完全合理，不必全盘西化——现代化 ≠ 抹掉所有日式元素。
- **用户拒收资产图时的路径**：用户对批量生成的场景帧/设定图不满意（「图片太丑了不需要」）→ **不要反复重出图**，改走纯文字描述编译 H3（角色图一仍可绑 Ref，场景/配角用文字全量锁定），镜头效果不受影响。

## 与其它 skill 的分工

- 世界观设定书 = 本 skill。后续分集/分镜/镜头表 = 微短剧创作 / 导演思维。H3 Ref2VA 提示词 = tag-h3 / ref2va-prompt-optimizer。执行层动画规范 = ai-2d-animation（§0.1 默认动漫2D风格规则、风格标记防漂移）。
- 这些均为用户自有 skill（curator 不可改），本 skill 是 curator 侧的工作流总纲。
