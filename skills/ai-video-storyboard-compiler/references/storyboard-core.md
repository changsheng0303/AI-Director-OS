# Storyboard Core

## 1. 先确定观众需要看见什么

每个镜头先回答：这一镜结束时，观众比上一镜多知道、感受或期待了什么？答案只能是信息、反应、行动阶段、关系、空间认知、揭示、对比或必要节奏。若只能回答“更电影感”，删除该镜头或改为固定机位。

## 2. 从剧本到镜头的最短路径

1. 锁定场次结果、原台词和不可修改事实。
2. 提取可见节拍：触发、人物行动、阻力、结果、反应和新状态。
3. 关掉声音检查：关键情绪是否能通过行为、目光、距离、道具或姿态理解。
4. 先设计人物调度，再决定构图和摄影机。
5. 只在观看重点真正变化时切镜。

不要把每句台词、每个动作或每个情绪词自动拆成一镜。

## 3. 空间与调度

简单场景只需写清人物相对位置、朝向和关键参照物。多人、追逐、出入口或复杂道具场景才建立空间图。

复杂场景至少确认：三个关键锚点；人物起点、朝向、视线和移动路线；当前轴线和默认屏幕方向；道具位置与持有者；主光方向、时间和天气。

位置变化允许省略完整路程，但必须有可理解的移动意图、动作、声音或场景切换。空间锁是内部准备，不默认要求用户先确认一次；只有参考图歧义会改变整场调度时才询问。

## 4. 可拍性与因果

复杂动作按以下链条检查：

```text
主体 → 起始位置 → 动作与方向 → 接触对象/物理连接 → 可见反应 → 结束位置或状态
```

拒绝结果无可见原因、道具无过程换手、人物受力方向错误、角色瞬移，以及用“突然/然后”掩盖缺失动作。

## 5. 切镜与覆盖

允许的主要切镜原因：`information / reaction / action_phase / spatial_clarification / contrast / reveal / rhythm_break`。

常见覆盖逻辑仅作选择，不是模板：

- 对话：空间关系 → 当前策略 → 对方反应 → 关系或决定结果。
- 动作：地理 → 准备 → 执行 → 接触/冲击 → 后果。
- 悬念：空间 → 线索 → 反应 → 暂时隐藏 → 揭示/重新解释。
- 喜剧：建立预期 → 误导 → 包袱 → 反应。

连续镜头默认共享至少三个锚点：人物、空间、方向、视线、道具、光线或动作阶段。改变超过三个关键变量时，使用移动、视线、声音、道具、中性镜头或明确场景切换作为桥。

## 6. 时长

先估计原台词说完时间、动作真实完成时间、必要反应/停顿，以及同步发生的摄影机运动。同步发生的动作和运镜不相加。

先确定镜头边界，再计算总时长；不以固定平均值反向制造切点。

## 7. 音频账本

对白、旁白、画外音和需要同步的关键声音各登记一次：说话者、原文、类型、所属场次和预计时长。最终检查不得遗漏、重复或把一条完整语义无授权拆开。

若上游台词包含 `logical_stress`，音频账本同时保留重音 span、语义角色和强度。分镜可以把可选 `delivery.visual_cue` 放进角色表演，并为停顿和听者反应留时间；不得重新推断重音、改原文，或强制用提高音量实现重音。

## 8. 生成片段分组

同一场景、同一人物位置关系、音频可容纳、动作物理兼容且模型负荷可控时，镜头可组合为一次生成。场景改变、动作不兼容、负荷过载、模型限制或叙事切点出现时拆分。

同一空间拆分时保留一个轻量连接锚点：未完成动作、视线、声音、同一道具、光色或遮挡。不要默认生成沉重的十项衔接卡。

## 9. 最小质量门

### P0

原台词/旁白遗漏或重复；时长不足；剧情结果被改写；角色、场景或参考资产被凭空发明。

### P1

结果缺少可见原因；人物位置、方向、视线或道具状态无法连接；连续动作被无理由切碎；一个镜头包含多个主要事件；镜头依赖隐藏上下文。

### P2

运镜装饰性过强；情绪仍是抽象词；输出包含用户不需要的内部表格、自检或技术字段。

先修最高级失败，并只重做受影响镜头或分组。
