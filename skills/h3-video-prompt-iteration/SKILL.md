# H3 视频提示词迭代工作流

当用户要求生成或**逐轮精化** MiniMax H3 六段式视频提示词（文生视频/图生视频）时使用。本技能是**工作流与交付约定**层；H3 六段式的创作法典（构图/情绪/时间线铁律/格式规范）在用户拥有的 `tag-h3` 与 `ref2va-prompt-optimizer` 技能里（勿编辑，它们是用户安装的第三方包）。

## 触发条件

- 用户说「生成视频提示词 / 文生视频 / H3 提示词」
- 用户对已生成的提示词做**小步迭代**：改风格（真实→日漫）、改面孔（亚洲/韩国）、改穿着（参考图）、改动作链、改镜头视角、改时长——每轮只动一个或少数几个维度
- 从剧本/小说里挑片段做视频

## 核心工作流（校验驱动）

1. **读素材**：剧本 docx 等用 read_file 提取全文，让用户圈定片段；没圈定时推荐戏剧性最强的冲突瞬间。
2. **加载法典**：skill_view 加载 `tag-h3` + `ref2va-prompt-optimizer`，并读 `references/ref2va-spec.md`（规范权威）——即使已加载过，写前再确认切点/段落格式。
3. **生成六段式**：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`，全英文（台词/可见文字除外）。
4. **写文件 + 校验**：提示词写入工作目录 txt 文件，然后跑校验：
   ```bash
   python "{Codex技能目录}/ref2va-prompt-optimizer/scripts/validate_ref2va_prompt.py" <prompt-file> --duration <seconds>
   ```
   **PASS（0 errors）才算完成**；ERROR 必须修掉再交付。
5. **交付**：中文一句话说明 → 改动对照表 → 完整六段式代码块 → 文件 MEDIA 链接 → 💡 生成提示（如逐镜预览、拆条生成建议）。
6. **迭代时**：只改用户点名的段落（角色外观→`subject_definitions`+`retention_analysis`+`detailed_description` 三处同步改；动作/视角→只动 `detailed_description`），其余结构原样保留；**全量覆盖同一个文件**，每轮重跑校验。

## 技法库

### 多步动作链（"拍→停→摸→抓"这类连续动作时）

- 把动作拆成**编号步骤**：`First ... Second ... Third ... Fourth ...`，每步独立一句
- **每步写清物理反应**：拍→布料颤动/臀肉 jiggle/胯前倾；停驻→掌压出浅凹痕；抚摸→布料随指泛波纹/肉随指移位；狠抓→手指深陷、软肉从指缝挤出、布料绷紧
- **给关键镜头分配足够时长**：动作链长的镜头单独加长（如 5 秒），其余镜头相应压缩，重排切点并保持递增且在时长内
- 音效/配乐同步动作节奏（拍=顿音、抚摸=渐强颤音、抓=低音重击）
- 特效偏好先问清楚：若要求「不要特效」→ 全片禁光点/光影/魔法效果，只写物理真实

### 参考图角色外观文字化

- 用户给角色设定图时：先 vision_analyze 确认细节（发色/耳尾/服装材质领口开叉/饰品/气质），再把外观写进 `subject_definitions` 英文描述
- 文生视频模式下外观**只能文字化**；若用户要 100% 保真，主动建议改用 Ref2VA 图生模式（图+视频）把参考图作为首帧/角色来源
- 参考图与文字描述冲突时以用户最新指令为准（如「参考图片的穿着，可以更暴露」→ 穿着抄图、暴露度按指令加深）

### 角色一致性（多物种混搭）

- 人类 / 半兽人（人脸+兽耳兽尾）/ 全兽人（兽头兽身）是常见设定分层，`subject_definitions` 里写明兽化程度限定句（如 `he is the only full human among the beastmen`）
- 面孔变更（亚洲/韩国）会连带改眼睛、眼妆、发色描述——一次改到位，避免半套

### 故事层 QA（用户说"故事跳/情绪对不上"时必查）

详细规则见 `h3-video-prompt-workflow` 的 `references/story-craft-for-h3.md`，要点：
- **开场 3 镜内传达关系前史**（道具/称呼/微表情，可被单帧读到）——否则亲密/冲突全被误读
- **情绪阶梯禁跳级**：觉察→犹豫→软化→默许→情动，每个跳级点必须有过渡节拍；15s 内情绪级 ≤3、信息点 ≤3
- **Beat 因果四问**：为什么现在发生 / 为什么这么做 / 为什么是这种方式 / 之后会怎样
- **相邻镜头 30/70**：70% 状态继承、30% 变化；共享锚点 ≥3；看向画外→下镜给被看对象
- 修复顺序固定：Story → Scene → Adjacency → Camera → Prompt，**不得从措辞层补剧情**

### L3 成人向内容（挑逗/裸露档）

- **身体接触必须晚于默许信号**：对视/放松/不再推拒 先于 手摸上去——"角色还没同意手已经摸上去了"= 跳级（用户多次反馈"故事很跳"的根源）
- **遮挡递进原则**：越接近隐私部位遮挡越密——隔衣（`through the fabric`）→ 衣物半掩 → 发丝/光影/雾气 → 裁切（`frame crops at`）；衣料写成**状态**而非约束（`silk pooling at her waist`、`sliding beneath the loose silk`），不堆"确保不脱衣"式防御措辞。**禁止剪影/黑场/关灯收尾**（用户明确纠正：L3/L4 要直面，转场回避=模板化，见 workflow 的 nsfw-grading §5）
- **遮挡三硬规则**：必须写清遮挡住的是**乳首**（`covering the nipple`，禁"veiling her breasts"模糊表述、禁"吊坠在两乳之间"错误位置）；**遮而不掩**（局部遮挡暴露乳周，裹严=没脱）；**裸露持续呈现**（脱完至少 1 镜停留，别立刻裹进大衣）
- **防裸露四原则**（生成时"脱衣→露全胸全乳头"的根因与对策）：① 写"剩什么"不写"露什么"（`wearing only a lace bralette` 替代 `upper body bare`）② 全段（含 retention）**绝口不提 nipple/breast 词** ③ 遮挡=穿着的衣物（bra/肚兜结构性遮挡，不用会动的手/发）④ 镜头裁切兜底（`the frame crops at her collarbone`）
- **三不原则**（用户定义的 L3 上限）：不露生殖器、**乳头必遮**（手/发/光影/雾气/衣物）、**臀部必遮**（衣物/床单/裁切），无完全裸露；"脱衣裸露"档位的极限 = 脱外衣→脱内衣→上身裸露（乳首遮）
- 用户要"更大胆"时：先加**过渡节拍**（犹豫/软化/默许）再加深动作，而不是直接跳到最后一步——过渡节拍本身也是张力
- **剧情驱动**：裸露必须是角色达成目标的剧情手段（关系/目标/冲突/反转四要素），不是"两个人站一起脱衣"的情境；反转在临界处（尺度给足后），禁"还没脱就反转"

## 陷阱

- `[Shot 1]` 不带时间戳；后续切点 `At MM:SS.mmm` 递增且在目标时长内
- 剧本没给台词原文 → **不要虚构 `<d>` 对话**，非语言人声（轻笑/叹息）放 `overall_soundscape`
- `retention_analysis` 每个独立主体恰一行，且 `subject_definitions` 定义的标签必须都在后续出现（无孤儿标签）
- 用户要求「分镜再细」时先问/判断时长上限（H3 文生视频 15s），镜头多了就压缩非重点镜头
- 交付时不要只给 diff——用户要**完整可粘贴的六段式**（平台要整条粘贴）
