## Deliberately not inherited as global requirements

The source documents were read in full, but the following are not promoted to universal system rules because they conflict with current authority, tool availability, or maintainability:

- mandatory multi-turn menu ceremonies when the user's intent is already clear;
- a fixed requirement that only one knowledge source may support a stage; the integrated system keeps one artifact authority while allowing bounded support;
- historical product rankings, pricing, model limitations, or platform-specific claims without current verification;
- forced use of a particular director, film, model, lens brand, aspect ratio, or palette;
- copying the Russian-language world template verbatim instead of preserving its world-rule structure;
- importing the original installer or project templates over the existing `simple-project.json` contract;
- any instruction to browse, generate, publish, purchase, or mutate external systems without the relevant current tool and user authority.

## Authority rule

The imported suite contributes methods, not duplicate top-level Skills. Existing system authorities remain responsible for Canon, Shot Table, assets, and engine syntax. If an imported method conflicts with approved project material or a current engine authority, the approved material and current authority win.
