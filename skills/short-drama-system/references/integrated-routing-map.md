# Integrated Routing Map

Use this map only when more than one installed skill appears applicable. It preserves one authority per artifact while allowing focused supporting knowledge.

| Need | Primary authority | Optional support | Must not own |
|---|---|---|---|
| Story, screenplay, episode structure | `screenplay-master` or the format-specific screenplay skill selected by the orchestrator | `ip-foundation-engine`, `universal-dialogue-core` | Shot numbering, engine syntax |
| Production shot table | `ai-video-storyboard-compiler` | `director-mindset`, `storyboard-script-spec`, behavioral-performance reference | Rewriting Canon or final engine syntax |
| Narrative visual assets | `ai-image-assets` | `character-design-director`, `series-image-director`, `cinema-dna-21x9x3` | Shot numbering or final video prompt syntax |
| Voice-over, SRT, tutorial, review, evidence-led information video | `reference-first-motion-director` | Asset or engine adapter selected after the visual master plan | Story Canon, production Shot Table |
| Seedance prompt | `seedance25-prompt-workflow` | single-shot physical-control reference; performance reference when already approved in the Shot Table | Rewriting story, dialogue, or assets |
| H3 prompt | Official `h3-prompt-writing` format authority through the appropriate local H3 workflow | Story/continuity checks and approved references | Inventing new source material |

## Direct entry

Enter the user's requested stage when the supplied material meets that stage's minimum needs. Record which files or attachments are authoritative. Missing upstream files are not blockers when equivalent user-approved material exists.

## Revision and impact

When the user revises an upstream artifact:

1. Preserve the previous version.
2. Change only the requested layer.
3. Record the changed IDs or scope.
4. Mark only dependent outputs as possibly stale.
5. Do not delete, regenerate, or silently rewrite downstream work.
6. Let the user choose whether to retain it, rebuild affected outputs only, or restart from a named stage.

## Imported-method boundaries

- Film concept, character, world, treatment, screenplay-fusion, and image-production methods from the imported suite are routed through the destinations recorded in [imported-ai-studio-film-suite-map.md](imported-ai-studio-film-suite-map.md); they are not installed as parallel authorities.
- The behavior-performance method enriches observable acting choices; it does not create new plot or dialogue.
- The single-shot physical-control method strengthens spatial and physical execution; it does not replace current Seedance format requirements.
- `reference-first-motion-director` is installed as an independent editorial branch. Its visual master plan may feed asset and prompt jobs, but it does not become the narrative source of truth.
