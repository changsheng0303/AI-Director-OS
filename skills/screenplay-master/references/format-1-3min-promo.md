# 1-3 Minute Promo Short Drama

## Goal

Use this format for product dramatic ads, brand shorts, IP promos, course/service conversion videos, brand attitude films, account launch videos, and event teasers. The goal is not a full long story; it is to create interest, trust, clicks, shares, inquiries, or purchase intent in a very short runtime.

## Percentage Structure

| Progress | Function |
|---|---|
| 0-5% | Abnormal image, conflict line, counterintuitive question, or result-first opening |
| 5-20% | Character situation, pain point, desire, and reason to keep watching |
| 20-45% | Escalating conflict; product, brand, or theme enters for a story reason |
| 45-70% | Reversal, evidence, emotional payoff, or value proof |
| 70-90% | Memory point, punchline, scene-based outcome, trust reinforcement |
| 90-100% | CTA, slogan, suspense, or next-content pull |

## Runtime Conversion

- 15 seconds: change information or action every 3-5 seconds.
- 30 seconds: keep only 1 conflict, 1 reversal, and 1 CTA.
- 60 seconds: allow a small beginning-middle-end, with no more than 2-3 characters.
- 90 seconds: allow one misunderstanding or evidence reversal.
- 180 seconds: allow a fuller character choice, but do not expand background.

## Rules

- Start with the hook, not background.
- Keep characters and locations limited.
- Make every action visible and easy to shoot.
- Do not insert the product mechanically. It must solve a conflict, create a misunderstanding, reveal evidence, or complete a reversal.
- For commercial content, check disclosure, claim substantiation, IP, and platform risk before drafting.

## Required Output

- Default assumptions
- Audience and platform
- Project type and screen orientation
- Logline
- Core hook
- Percentage beat sheet
- Full script
- Visual/action cues
- Sound/subtitle cues
- CTA or next-content pull
- Risk check
