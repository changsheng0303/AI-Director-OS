# Review Checklists

Use this six-gate pipeline for every substantial output. If a gate fails, revise before delivering.

## Scoring Gate

- Overall target: 90/100 or higher.
- Any core category below 80% returns to rewrite.
- Hard failures override total score.

| Gate | Weight | Passing standard |
|---|---:|---|
| Structure | 20 | Opening, ending, main line, subplots, and beat sheet match format and runtime. |
| Character | 15 | Desire, obstacle, wound, choice, change, and motive are stable. |
| Hook/rhythm | 20 | First 3-10 seconds or first episode hooks; escalation, reversal, payoff, and cliffhanger work. |
| Dialogue | 15 | Oral, short, high-density; dialogue creates conflict instead of explaining setting. |
| Format | 15 | Correct output mode; not redundant; timecode/image/action/dialogue/CTA or cliffhanger included when needed. |
| Continuity | 15 | Names, relationships, timeline, setups/payoffs, platform, duration, and risk assumptions stay consistent. |

## Return Rules

Structure:
- Missing logline, core hook, ending payoff.
- Middle piles events without irreversible main-line progress.
- Series lacks episode problem and next-episode pull.

Character:
- Protagonist has no clear desire or final choice.
- Character behavior only serves a twist.
- Antagonist/pressure does not mirror or challenge protagonist.

Hook/rhythm:
- Opening begins with background.
- Runtime structure does not fit 30/60/90/180 seconds.
- No stage payoff every 3-5 episodes.
- Ending lacks cliffhanger or emotional residue.

Dialogue:
- Long explanation of setting.
- All characters speak alike.
- Lines lack conflict, pressure, punch, or information density.

Format:
- User asks for review but receives only new creation.
- User asks for shootable script but cues are absent.
- Commercial/release scenario lacks risk check.

Continuity:
- Names or relationships change unexpectedly.
- Setups are not recorded or paid off.
- Timeline breaks.
- Platform, region, AI, copyright, or disclosure assumptions contradict each other.

## Hard Failures

- Mis-trigger: ordinary news, essay, slogan, coding, or legal analysis treated as a screenplay task.
- High-risk compliance missing: medical, finance, education, health, beauty, minors, AI, commercial placement, copyright/IP.
- Copyright imitation of existing distinctive plot, line, character setting, or set piece.
- Output cannot be used by writer, director, editor, or reviewer.
