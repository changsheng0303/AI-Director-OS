# Character Arc System

## Character Card Fields

- Name
- Function: protagonist, antagonist, pressure, ally, mirror, relationship catalyst
- Surface goal
- Deep desire
- Wound
- Flaw
- Secret
- Relationships
- Arc
- Representative line
- Initial state
- Irreversible choice
- Final state

## Conflict Dimensions

- Desire vs obstacle: what the character wants and what blocks it.
- Surface goal vs deep desire: external task and inner need should create pressure.
- Wound vs growth: old injury limits action until the plot forces change.
- Flaw vs cost: the flaw must create consequences.
- Secret vs reveal: secrets should drive misunderstanding, reversal, and relationship shifts.
- Misunderstanding vs truth: misunderstanding must be visible, escalated, and paid off.
- Stable relationship vs reversal: trust, alliance, betrayal, dependence, or separation changes.
- Protagonist vs antagonist mirror: the antagonist should challenge or reflect the protagonist's flaw.
- Main line vs subplot: subplots must serve the main conflict.
- Episode problem vs next pull: each episode should resolve something and open something.

## Arc Checks

- The protagonist has a clear flaw, desire, wound, and growth direction.
- The plot contains choices, not only events.
- The climax forces an irreversible choice.
- The ending shows change or exposes a deeper cost.
- Antagonist/pressure is not only a tool; it challenges the protagonist's core weakness.
- Relationship changes are traceable through scenes.
- Every key turn changes at least one of: goal, relationship, information, cost, emotion.
- If a motive changes, a scene must justify the change.
- In series, every 3-5 episodes should pay off a stage of the arc.
- Secrets and relationship reversals must be tracked in continuity notes.
