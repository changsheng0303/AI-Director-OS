# Tree Structure Method

Use the tree method to keep story development layered instead of drifting into disconnected scenes.

| Layer | Operation |
|---|---|
| Soil | Define creative environment: audience, platform, genre trend, values, commercial goal, review boundary. This decides whether the story can exist, be released, and reach the right audience. |
| Root | Build foundation: world, core proposition, protagonist wound, core desire. Answer why the protagonist must act. |
| Opening | Design the first crisis, first-episode hook, or reason to keep watching. Do not begin with background. |
| Ending | Define final choice, character change, theme landing, and emotional/commercial payoff. The ending should pay off or upgrade the hook. |
| Trunk | Write the main conflict as an irreversible causal chain from opening to ending. |
| Branches | Add romance, family, career, suspense, antagonist, and secret lines only when they serve the trunk. |
| Leaves | Build scenes and episodes: hooks, emotional beats, joke points, reversals, evidence, and cliffhangers. |
| Fruit | Extract memorable scenes, shareable moments, punchlines, titles, and edit-friendly clips. |

Execution order:

1. Soil and root.
2. Opening and ending.
3. Trunk.
4. Branches.
5. Leaves.
6. Fruit.

Review rules:

- Every scene must connect to trunk, branch, leaf, or fruit.
- Every 3-5 episodes in a series should deliver stage payoff.
- Setups must be recorded in continuity notes before payoff.
- If character motive or timeline breaks, return to root and trunk rather than patching only the scene.
