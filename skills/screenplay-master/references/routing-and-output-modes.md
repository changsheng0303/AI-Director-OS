# Routing and Output Modes

## Trigger Boundaries

Use `screenplay-master` when the user asks to create, plan, revise, or evaluate short drama, micro-drama, vertical series, scripted short video, dramatic ad, promo film, episode outline, hook opening, cliffhanger, reversal, character arc, series bible, or script doctoring.

Do not use it for ordinary prose, novels, essays, news releases, academic writing, pure ad slogans, pure social copy, coding tasks, market analysis, or legal/regulatory consultation unless the user explicitly asks to turn the material into a script or scripted video.

If required information is missing, proceed with reasonable default assumptions. Ask for clarification only when commercial compliance risk is high, platform/region regulation is central, or the user requires exact duration or budget but has not provided it.

## Task Routing

| Task type | Read | Output |
|---|---|---|
| 1-3 minute promo short drama, dramatic ad, brand short | `format-1-3min-promo.md`, `commercial-script-rules.md`, `platform-playbooks.md`, `compliance-and-platform-risk.md` | Assumptions, audience, core hook, percentage beat sheet, full script, CTA, risk check |
| 4-6 minute complete short film | `format-4-6min-short-film.md`, `character-arc-system.md`, `dialogue-and-scene-style.md`, `review-checklists.md` | Logline, character goal, structure, scene outline, full script, self-check |
| Vertical micro-drama series | `format-micro-series.md`, `tree-structure-method.md`, `hook-library.md`, `continuity-system.md`, `compliance-and-platform-risk.md` | Series setup, character relationships, main/subplots, first 3 episode outlines, season table, hooks/cliffhangers |
| Long series development | `format-long-series.md`, `tree-structure-method.md`, `character-arc-system.md`, `continuity-system.md` | Series bible, character arcs, main/subplots, season/episode structure, turns, ending |
| Existing script revision or review | `review-checklists.md`, `hook-library.md`, `dialogue-and-scene-style.md`, `compliance-and-platform-risk.md` | Diagnosis, severity-ranked issues, revision strategy, rewrite, rationale, remaining risks |
| Genre strengthening | `genre-playbooks.md`; add `character-arc-system.md`, `hook-library.md`, or `review-checklists.md` as needed | Genre rules, emotional/comedy/suspense beats, trope risks, alternative beats |

## Output Mode Routing

- If the user only asks for direction, use Quick Concept Mode.
- If the user asks for an outline, use Outline Mode.
- If the user asks for something shootable, use Full Script Mode.
- If the user provides an old draft, use Review and Rewrite Mode.
- If the user mentions release, platform, commercial use, sponsorship, AI generation, copyright, or region, add Compliance Check Mode.
- Read only the references needed for the current task; avoid loading the whole reference set by default.

## Mode Fields

Quick Concept:
- Default assumptions
- Project type
- Audience and platform
- Logline
- Core hook
- Ending payoff
- 3 title directions
- 3 risk reminders

Outline:
- Default assumptions
- Project type
- Audience and platform
- Logline
- Tree structure
- Character table
- Main line
- Subplots
- Beat sheet
- Scene or episode outline
- Self-check report

Full Script:
- Default assumptions
- Project type
- Production specs
- Beat sheet
- Full script
- Visual/action cues
- Sound/subtitle cues
- CTA or cliffhanger
- Self-check report

Review and Rewrite:
- Diagnostic summary
- Severity-ranked issues
- Revision strategy
- Revised version
- Key change rationale
- Unresolved risks

Compliance Check:
- Release region and platform assumptions
- Obvious risks
- Required rewrites
- Commercial disclosure suggestions
- AI-generation and copyright notes
- Statement that the check is not legal advice
