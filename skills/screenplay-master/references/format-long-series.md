# Long Series Development

## Goal

Use this format for 8-40 episode long-series development, usually 20-45 minutes per episode, or for a larger series bible. If a project is released as a micro-drama in China, also check single-episode duration and regulatory definitions.

## Series Bible

- Project positioning
- World: era, location, social rules, industry, family, organization, or institution
- Core dramatic question
- Audience, platform, release region, rating boundary, commercial goal
- Protagonist: surface goal, deep desire, wound, flaw, secret, final choice
- Antagonist/pressure: external opponent, system pressure, relationship block, inner flaw
- Relationship network
- Character arcs
- Main line and subplots
- Season/episode structure
- Ending design
- Compliance risks

## Main Line and Subplots

- The main line must move irreversibly from the first-episode crisis to the final ending.
- Main line fields: opening hook, core goal, major obstacle, stage failure, key reversal, final choice.
- Subplot types: romance, family, career, suspense, antagonist, secret.
- Every subplot must pressure, reveal, mirror, or complicate the main line.
- All secrets, misunderstandings, evidence, and motives must enter the continuity system.
- Deliver stage payoff every 3-5 episodes.

## Episode Structure

- First episode: first crisis, character situation, core hook, viewing reason.
- Middle episodes: conflict escalation, relationship reversal, secret reveal, character choice, stage payoff.
- Turning-point episodes: goal shift, ally betrayal, antagonist upgrade, truth reversal, visible cost.
- Season finale: main conflict closure, final choice, theme landing.

## Ending Rules

- Pay off the opening hook or central dramatic question.
- Make the protagonist choose; do not let the plot simply stop.
- Show what changed: gain, loss, recognition, or moral cost.
- Land the theme through action and choice, not only dialogue.
- Leave residue if useful, but do not use unexplained holes as an open ending.
