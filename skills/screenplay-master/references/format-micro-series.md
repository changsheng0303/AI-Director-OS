# Vertical Micro-Drama Series

## Goal

Use this format for 20-80 episode vertical micro-drama, usually 1-3 minutes per episode. The goal is continuous viewing through character arc, main conflict, subplot traction, per-episode hooks, and cliffhangers.

## Required Structure

- Series setup
- Character relationships
- Main line
- Subplots
- First 3 detailed episode outlines
- Full-season episode table
- Opening hook and ending cliffhanger for every episode
- Continuity notes for secrets, timelines, and payoff

## First 3 Episodes

Episode 1:
- Open with crisis, abnormal result, or emotional rupture.
- Establish protagonist dilemma, core desire, and reason to keep watching.
- End with an irreversible event.

Episode 2:
- Expand the conflict.
- Reveal a key relationship, secret, or power imbalance.
- End with a stronger misunderstanding, threat, or choice.

Episode 3:
- Deliver the first small payoff.
- Introduce the real opponent or deeper cost.
- Create a clear reason to continue to episode 4.

## Episode Table Fields

- Episode number
- Opening hook
- Episode problem
- Main conflict
- Key reversal
- Emotional payoff
- Ending cliffhanger
- Setup/payoff note

## Rules

- Each episode must have both an episode problem and a next-episode pull.
- Every 3-5 episodes must deliver substantive progress; do not only delay.
- Define the beginning and ending first, then trunk, then branches.
- Record all secrets, setups, evidence, relationship shifts, and timeline constraints in the continuity system.
- For China-facing public release, check the current definition and management rules for micro-dramas before finalizing.
