# Continuity System

## Track These Items

- Character names, aliases, roles, and relationships
- Core desire, wound, flaw, secret, and current goal
- Timeline: day, location, episode, and elapsed time
- Setups: clue, prop, promise, line, debt, injury, secret
- Payoffs: when and how each setup returns
- Relationship shifts: trust, conflict, alliance, betrayal, dependence, separation
- Platform, region, commercial, AI, and copyright assumptions

## Continuity Table

| Item | First appears | Current status | Payoff target | Risk |
|---|---|---|---|---|
| Character motive | Episode/scene | Stable/changed | Scene/episode | Unjustified change |
| Setup | Episode/scene | Open/paid off/dropped | Scene/episode | Forgotten clue |
| Timeline | Episode/scene | Day/time/location | Next scene | Impossible timing |
| Relationship | Episode/scene | Trust/conflict/etc. | Next turn | Sudden change |
| Risk assumption | Start | Region/platform/commercial | Final check | Inconsistent compliance |

## Rules

- Every major secret, misunderstanding, and evidence item must have an owner and payoff target.
- Relationship changes require a visible cause.
- Time jumps must be marked.
- A character cannot know information they have not learned on screen unless the script states the offscreen source.
- Do not let subplots run for more than 3-5 episodes without progress or payoff.
- If a rewrite changes an earlier motive, scan later episodes for contradictions.

## Change Log

For revisions, record:

- Changed premise, character, or event
- Affected episodes/scenes
- Required downstream updates
- Remaining continuity risk
