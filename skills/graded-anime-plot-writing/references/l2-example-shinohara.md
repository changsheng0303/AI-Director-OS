# 样例：《屏风后的叛逃》— 篠原凉子 L2（2026-08 已交付定稿）

> 结构模板：改角色/场景/级别可复用。完整原文：`{当前工作区}\剧本\《屏风后的叛逃》凉子L2剧情.md`

## 一句话（Hook）
被安排联姻的大小姐在更衣间里一边脱衣一边策划叛逃，被看守撞破——而他递来的不是礼服，是逃跑的便服。

## 四要素落法（可复用的"更衣+秘密"模式）
- 关系：大小姐 × 家臣之子（看守/影子）。
- 目标：她叛逃 vs 他看守。
- 冲突：必须**当着他的面**更衣（家族规矩不让看守离岗）+ 礼服里缝着定位器（她跑不掉）。
- 反转：尺度推到满格时他先开口"你想逃，对吧"——他不是来抓她的，是来递钥匙的（便服+路线+假象）。

## 角色弧线
- 女主：精致人偶（清冷服从）→ 决意挣脱 → 临界处破防 → 信任他，第一次露真实表情。
- 男主：尽职看守（不敢看她）→ 早已看穿 → 背主递钥匙 → 抛钥匙后耳尖红。

## 分场三幕（场景锁：篠原家富贵名门版）
1. 和室（建立）：背对镜头立屏风前，门外脚步声停——"站那儿。我换衣服。"
2. 屏风后更衣间（主戏）：半脱递进 + 反转临界。
3. 桧木缘侧走廊（余韵）：换好便服快步走，他抛钥匙，侧门月光涌进——"谢了，看守大人。"

## 合规自检（L2 模板清单）
- [ ] 半脱两级齐备（bra 全展示 + 罩杯滑落露半胸）
- [ ] bra 在身上（"按回原位"动作明确）——封顶 L2 不越 L3
- [ ] 暴露梯度递增不跳档（前奏→肩颈→bra→半胸）
- [ ] 三不零出现；臀部被裙料/下摆/构图罩住
- [ ] 服装性暗示（蕾丝内衣）；直面无转场（遮挡全为画面内元素）
- [ ] 四要素齐备；反转在尺度满格**之后**
- [ ] 角色弧线完整；学生角色不涉性；气质克制

## 复用要点
- 换级别：半脱两级→L3 需完整脱内衣动作（解扣→滑落→构图挡乳首）+ 裸露 ≥3 区持续呈现；L4 无遮挡直呈。
- 换角色：四要素里的"秘密"（定位器）可换成任何让"更衣"成为剧情必要条件的机制——试衣/药膏/伤口/湿衣/拉链卡住。
- 换场景：纸屏风=天然画面内遮挡物，优先用场景契约里的隔断元素（障子门/纱帐/浴帘）。
