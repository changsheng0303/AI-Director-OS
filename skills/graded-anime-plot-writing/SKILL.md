# 分级剧情撰写（L2/L3/L4 卖肉福利番）

## When to use
- 用户要求"撰写一个 L2/L3/L4 的剧情/剧本"，主角是既定角色（凉子/彩乃/花穗等），有场景图/场景契约资产。
- 输入通常是：角色参考图（人设）+ 场景图/场景契约（如篠原家富贵名门版）+ 级别要求（L2 等）。
- 与下游衔接：写完剧情文档后可编译 H3 Ref2VA 提示词（tag-h3/ref2va-prompt-optimizer）或分镜（导演思维）。

## 交付结构（6 段，缺一不可）
1. **剧情卡片**：标题/类型/级别/女主角/男主角/场景/时长/一句话。
2. **剧情四要素**：关系（两人是谁）→ 目标（各自要什么）→ 冲突（阻力）→ 反转（临界处转折）。
3. **角色弧线**：每个角色"起点人设 → 破防点 → 变化 → 落点"。
4. **分场剧本**：场景锁（用既有场景资产，标注起/主戏/余韵三场），带台词。
5. **镜头设计表**：10 镜 × ~5s（8-12 镜，0.4-0.7s/镜），列景别/画面内容/台词/尺度标注；直面连续无转场。
6. **合规自检清单**：逐项打勾（见下），生成前必过。

## 分级速查（2026-08 用户定稿）
- **L1** < **L2** < **L3** < **L4** 暴露递增。
- **L2 = 穿着状态极大露出 + 半脱两级**：① 罩杯滑落露半胸（乳首区由 bra 边缘/手臂/发丝/构图遮）② bra 全展示（蕾丝/透视，bra 是穿着主体）。**bra 在身上 = L2；bra 脱掉 = L3**。半脱（衣料滑一半）= L2 专属，永不冒充 L3。
- **L3 = 完整脱内衣 + 隔衣模拟**，三不（生殖器/乳头/臀部必遮）；L3 三定律：裸露呈现 ≥3 区（肩/背/腰/腿）+ 构图只挡乳首区 + 尺度先于剧情。
- **L4 = 无遮挡直呈**（2026-08 修订：三不/遮挡/防雷词仅约束 L3 及以下）。
- **服装性暗示前提**：脱衣前服装须性暗示（蕾丝/网袜/吊带/丝质/PVC 高开叉），机能装连 L1 都不算。
- **三不**：生殖器/乳头/臀部零出现；臀部永远被裙料/下摆/构图罩住。
- **直面原则**：禁黑场/定格/剪影/关灯/切镜回避成人内容；遮挡只用画面内元素（发丝/手/衣料/纸屏风/光影/雾气）。
- **剧情驱动**：裸露是达成目标的剧情手段，不是"站着脱衣"；四要素齐备。
- **反转位置**：尺度给足 + 反转在临界处（先推到满格，再反转）；禁"还没露就反转"。
- **气质克制**：温柔/清冷/梦幻/优雅/慵懒/神秘/知性等；禁低俗/媚俗/廉价网红感；冲突组合互斥。
- **裸露对称**：男角色也可解扣露胸腹（无需遮挡物，不受三不约束）；她脱他脱互脱皆可。
- **执行层底线**：学生角色不涉性；未成年/非自愿/暴力/强暴类任何模型平台均拒。skill 文本零安全条款，约束只在执行层。
- **评分参考**：夜晚场景 ≤2.5 级；电梯 2 级；半脱 = 2 级。

## 工作流程
1. **确认角色与场景资产**：先查人设延续——剧本目录 `{当前工作区}\剧本\`、角色图 `{用户下载目录}\高等女子学院\`、场景契约 `{当前工作区}\h3-prompts\<作品>\`；角色人设（如凉子=白毛水手服大小姐·清冷）不可写崩。
2. **分析场景图**：>10MB 先 PIL 压缩（thumbnail 1400 + JPEG q88）；视觉分析用 glm-4v/gpt-4o-mini（luna 吞 token 吐空，见 hermes-image-analysis）。场景契约优先于看图（富贵名门版=桧木/黑檀/金箔/和纸暖光/榻榻米）。
3. **定四要素**：关系/目标/冲突/反转先行——这是剧本骨架，先写死在文档里再写分场。
4. **定角色弧线**：每人一行起点→破防→落点。
5. **写分场剧本**：起（建立+关系）→ 主戏（尺度递进本体）→ 余韵（反转落地/收束）。台词要少而准。
6. **编镜头表**：10 镜 × 5s；尺度标注列逐镜写档位（半脱①/②/③）；镜头连续性锁（发色/空间/光色温不跳变）。
7. **自检**：对照合规清单逐项打勾；不过关就改，不交付。

## L2 镜头分配黄金比例（10 镜示例）
```
镜1-2  建立+关系（场景+看守/对峙，零尺度）
镜3-4  半脱前奏→半脱①（领口/肩颈裸露，发丝遮）
镜5    半脱② bra 全展示（L2 定级镜）
镜6    半脱③ 罩杯滑落露半胸（L2 满格，发丝+手臂遮乳首区）
镜7    反转临界（尺度满格之后才反转——先尺度后剧情）
镜8-9  反转落地（裸露持续呈现中对话；"按回原位"动作=bra 在身上证明）
镜10   余韵收束（换装后状态，光色温收尾）
```

## Pitfalls
- **"图一/参考图"处理**：用户说"男主图已有/图一"但消息里未必有附件文件。先查常见图片目录（Downloads/Desktop/{当前工作区} 最近 -mmin/-mtime 的 png/jpg/webp；{应用缓存目录}\images 可能为空）；查不到就在输出中用【图一：男主角】占位标注继续写剧情（不阻塞），文末请用户发图；收到图后 vision_analyze 对齐人设卡（外貌/服装/气质/视觉锚点）并更新 memory IP 条目。完整流程见 `references/foodgasm-foodbattle-template.md`。
- **尺度先于剧情**：剧情/张力给足 ≠ 尺度达标；观众没看到裸露 = 不达级。反转前必须先把半脱推到满格。
- **写"剩什么"不写"露什么"**：中文剧情同样适用——写"只剩白色蕾丝内衣"（bra 全展示）不写"袒胸"；乳首区永远由发丝/手臂/构图交代。
- **学生角色不涉性**：更衣擦边可，性行为不可；感情线止于"信任/心动"，不写实际性行为。
- **人设延续**：同一角色在不同剧情的性格基线（凉子=清冷疏离大小姐）要保持，破防才有反差；先查剧本目录再动笔。
- **场景资产复用**：优先用既有场景契约（篠原家富贵版等），不重新发明空间；纸屏风/障子门等是天然画面内遮挡物，优先利用。
- **视觉分析坑**：luna 模型 max_tokens 全被 reasoning_tokens 吃掉返回空 content；>10MB 图先压缩；image_url schema 报错直接走直连客户端（详见 hermes-image-analysis 技能）。
- **3渲2 问题（爆衣番视频生成，2026-08 实证）**：H3/Seedance 系视频模型默认把"动漫"理解成 3渲2（体积光+材质反光+轻景深）。修复优先级：① **换参考图**——用设定图（白底/多视图/静态）当 Ref 是 3渲2 主因，模型把设定图的"渲染质感"直接继承进视频；改用 TV 动画单帧感参考图（动态构图+场景背景+赛璐璐硬边），模板见 image-generation-api `references/tv-anime-frame-ref.md`。② 提示词补压制词：`Flat 2D hand-drawn TV anime cel animation style` + `no 3D render, no CGI, no volumetric lighting, no realistic material reflections, no depth of field`。③ 仍不行=模型能力上限，换平台（即梦 Seedance/Vidu 的 2D 支持更强）。反 3D 词加在 detailed_description 开头句，不要只依赖 subject_definitions。
- **防雷词子串陷阱**：`double-breasted`（双排扣）含 "breast" 子串，L3 防雷扫描会误命中 → 服装描述改用 `double-buttoned` / `twin-button line`。**无辜词也会被扫**：`barely` 含 "bare"、`barefoot` 同理——动作描写用 "just a little" / "slightly" 替代。交付前跑全串扫描：`grep -inE "nipple|breast|boob|bare|naked|nude|penis|vagina|dick|cock|pussy|\bsex\b" <files>`，命中即返工（含 retention_analysis 和 subject_definitions，不只查 detailed_description）。
- **新 IP 默认双人核心局**（2026-08 实证）：用户砍掉女二，要求聚焦男主×女主单线。配角（评审/反派伏笔/工具人）只做功能位，不设常驻女二副线；四要素与分场围绕双人张力设计。
- **脚本交付形态**：用户要求"剧情脚本给我看"时，完整分场剧本（三场带台词+镜头表）直接在聊天内全文展示，文档同步存档 `{当前工作区}\剧本\`；不要只给大纲、不要等确认才出剧本。
- **原创角色补阵容**：新 IP 无既有角色图时，按人设卡生成四视图 character sheet（模板：image-generation-api `references/character-sheet-prompts.md`），格式对齐用户已有角色图版式，生成后 vision_analyze 质检再动笔。

## 每集微擦边节奏（福利番硬性要求，2026-08 实证）

- 用户要求**每集至少 1 镜 L1-L2 微擦边**，即使纯剧情/情感集（夺店/告别/铺垫）也不能整集零擦边——「第一集没有微擦边的镜头」会被直接打回。衣裂/爆衣满格可以后置到关键集，但每集都要有甜头。
- 微擦边写法（L1-L2，穿着状态，干净不涉性）：**动作触发**（弯腰接物/踮脚够高架/俯身递物）+ **环境加成**（蒸汽拂面/暖光/发丝沾湿脸颊微红）+ **低角度仰拍**；露锁骨/胸线上缘/后颈/腿线即可，不露乳首、无性暗示动作、无身体接触。
- 插入位置：集内"日常/过渡"段（打工场景、街坊排队、更衣前奏），不打断主线情绪；**先暖后冷可强化主线反差**（例：居酒屋暖光擦边 → 归来看见祖父发呆，反差更强）。
- 角色：一次性配角（居酒屋老板娘/年轻常客）不违反"无女二"设定；学生角色只做"目光移开+耳根微热"的克制反应，不涉性。
- 台词给擦边一句家常话（「朔夜，下班啦？」「最后一碗——给我多盛点！」），让擦边有剧情功能（交代生计/街坊人情），不是纯福利插入。
- 环境适配：现代环境（小饭馆/居酒屋）下擦边用常服/浴衣均可——浴衣在现代日本居酒屋完全合理，不违和。

## 下游：整集 H3 提示词包（2026-08 实证）

用户要求"生成提示词，把完整的一集给我"时，已验证组织模式（《爆衣味觉学园》EP01，四段全 PASS）：

- **拆分**：50s 整集按用户偏好拆 **3×15s 主段 + 1×5s 尾段**（镜1-3 建立 / 镜4-6 爆衣满格 / 镜7-9 反转 / 镜10 伏笔），每段一个独立 Ref2VA 六段式文件，不要一段装全片。
- **参考图绑定**：角色设定图统一编号 `<Picture 1>`（男主图一）/`<Picture 2>`（女主设定图），只作 `<Subject N>` 外观来源引用，不独立定义（ref2va-spec 硬规则）。
- **台词原文**：`<d>[Chinese] 原话</d>` 一字不改；说话者按段内首次发声分配 (S1)/(S2)。
- **校验**：逐段跑 `python {Codex技能目录}/ref2va-prompt-optimizer/scripts/validate_ref2va_prompt.py <file> --duration <sec>`，全部 0 error 才算交付。
- **存档**：`{当前工作区}\h3-prompts\<作品>\`，命名 `EP01_SEG<N>_<段名>_<秒数>s.txt`。
