# Coverage Audition — 关键场次导演方案比较

源自生产实践：**第一种合理拍法不应直接成为唯一答案**。关键场次（情绪顶点、信息揭示、动作高潮、关系转折）值得先比较多种真正不同的观看方法，再让创作者选择。

## 何时使用

- 场次存在**多种真正不同**的观看方式（视角选择明显改变体验）。
- 场次是剧本的关键节点（第一镜、揭示镜、高潮镜、结局镜）。
- 导演/用户明确要求"比较方案"。

普通场景**跳过本层**，不为流程完整补 audition。只存在一个明确方法时直接写计划。

## Audition 比较维度

对每个候选方案，逐项回答：

| 维度 | 问题 |
|---|---|
| 信息时机 | 关键信息在什么时刻、以什么顺序被观众知道 |
| 对齐对象 | 观众认同/跟随谁的位置、视线、情绪 |
| 表演空间 | 角色在画面中的调度与互动关系如何被呈现 |
| 最强画面 | 本方案最有记忆点的单帧是什么 |
| 落点 | 方案结束时观众停在什么情绪/悬念上 |
| 损失 | 选择本方案失去了什么（信息/氛围/节奏） |
| 制作相容性 | 是否匹配目标模型能力、成本、时长限制 |

## 输出格式（CSV 或表格）

```
方案, 信息时机, 对齐对象, 表演空间, 最强画面, 落点, 损失, 制作相容性, 推荐度
方案A-正面直拍, 第2镜揭示, 主角, 对称站位, 对视特写, 悬念, 失去对手视角, 高, ★★★★
方案B-对手视角, 第3镜揭示, 对手, 过肩构图, 主角入画, 压迫感, 失去主角内心, 中, ★★★
方案C-全景冷眼, 全程客观, 观众, 人物缩小, 剪影对峙, 疏离感, 失去情绪, 高, ★★
```

## 选择后

1. 创作者选定方案后，将其写为整场视觉计划：戏剧转向、观众立场、空间压力、视觉推进、摄影节奏、反应落点、声音策略。
2. 视觉计划成为该场每个 Shot Contract 的 `continuity_in` 依据——镜头不是给动作段落加几个摄影形容词，而是投影整场计划的一段变化。
3. 未选中的方案归档（可作备用/重拍参考），不丢弃。

## 边界

- 本层**不新增剧本/资产事实**：不发明剧情、不改台词、不加角色。
- 不固定方案数（2-4 个均可）、不固定宫格或镜头数。
- 每镜的 `shot purpose`、`duration`、起止边界仍由 Shot Contract 拥有，audition 只比较"怎么拍"，不替代"拍什么"。
