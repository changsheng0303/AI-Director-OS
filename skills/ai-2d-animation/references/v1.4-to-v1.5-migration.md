# V1.4 → V1.5 Migration

旧项目最小迁移：
1. 为 Story 增加 Story Contract。
2. 为每个 Scene 增加 Scene Contract。
3. 为每个 Beat 增加 Trigger/Action/Result/New State。
4. 为每个 Shot 增加 Previous Shot/Adjacency/Start State/End State/Spatial Anchor/Bridge Reason。
5. 连续镜头至少补 3 个共享锚点。
6. 旧 Prompt 不直接废弃；重新从新 Contract 编译。

如果用户已有成熟分镜，只做“审计补字段”，不擅自改变剧情。
