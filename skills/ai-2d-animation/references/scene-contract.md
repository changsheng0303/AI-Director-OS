# Scene Contract V1.5

每场戏必须是一个“完整的戏剧单元”，不是地点标签。

字段：
`scene_id / goal / conflict / participants / location_anchor / entrances_exits / spatial_map / screen_direction_default / eyeline_map / prop_anchors / lighting_anchor / time_weather / tactic / complication / turn / exit_state / transition_to_next_scene`

## Scene Turn
Scene 必须发生一次明确变化：
- 信息被揭示/隐藏
- 目标改变
- 关系升/降级
- 风险增加
- 空间控制权改变
- 时间压力增加

## Exit State
下一场必须能从 Exit State 解释为什么开始在那里、角色为什么处于该状态。
