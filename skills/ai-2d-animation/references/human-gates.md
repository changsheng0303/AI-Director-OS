# Human Approval Gates V1.2

## Gate A — Intent/Bible
Approve: target, hook, characters, visual language, tone.

## Gate B — Shot Design
Approve: Beat, key shots, composition, acting, rhythm, continuity.

## Gate C — Hero Keyframes / First Cut
Approve: character identity, style lock, key performance, action readability.

## Gate D — Final Cut
Approve: story clarity, emotional curve, pacing, sound, overall visual consistency.

## Automation Boundary
Automatic: schema, fields, versions, duration, enum, duplicate IDs, continuity fields, budget fields.
Human: taste, dramatic effectiveness, performance quality, style desirability, final pacing.

A human gate should stop downstream generation when a locked creative decision is not approved.
