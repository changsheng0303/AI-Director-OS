# Action 类型模板

核心：空间定位 → 预备 → 爆发 → Impact → Recovery → Reaction。

## Beat 结构
1. 空间定位（establish geography）：让观众知道战场格局与双方位置
2. 预备（anticipation）：蓄力、对视、对峙节拍
3. 爆发（burst）：主攻击动作（单个主动作）
4. Impact：命中/接触帧（冲击帧+白闪+声音咬合）
5. Recovery：动作后收势（喘息/站稳）
6. Reaction：对手/队友反应镜头（确认结果）

## 规则
- 高速镜头必须由静态/低速建立来衬托。
- 复杂动作拆多个 Shot；每 Shot 一个主动作。
- 高燃战斗 setup 见 shots-library.md §1（Long Lens Stunt → Matching Motion → Cutting For Impact）。
- 情绪阶梯：专注→蓄势→爆发→释放→满足（勿跳级）。
