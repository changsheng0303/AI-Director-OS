# Suspense 类型模板

核心：信息控制。

## Beat 结构
1. 异常建立（anomaly）：日常中的不对劲（声音/细节/缺失）
2. 局部特写（partial reveal）：只给部分信息（遮挡/暗部/门缝）
3. 延迟揭示（delay）：拉长"即将知道"的过程
4. 声音先行（sound first）：声音先于画面（脚步/呼吸/敲门）
5. 错误线索（red herring）：引导观众误判
6. 揭示（reveal）：真相释放（REVEAL 时刻）
7. 后果（consequence）：真相带来的新威胁

## 规则
- 使用遮挡、局部特写、留白、声音先行、延迟揭示（见 narrative-camera-logic.md）。
- 不要过早展示答案：WITHHOLD 必须有对应 REVEAL（story-craft.md §4）。
- 信息差是核心引擎：观众知道 > 角色知道，或反之。
- 节奏：越接近揭示，镜头越短越快（editing-rhythm.md 加速法则）。
