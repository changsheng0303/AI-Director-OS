# Comedy 类型模板

核心：Expectation → Hold → Deviation → Reaction → Punchline → Exit。

## Beat 结构
1. Expectation：建立观众预期（常规场景/常规行为）
2. Hold：停在预期上（给观众"马上要按预期走"的信号）
3. Deviation：偏离预期（反转/误读/意外）
4. Reaction：角色反应（颜艺/豆豆眼/慢半拍）
5. Punchline：笑点落点（最响的一帧）
6. Exit：出画/转场（余笑）

## 规则
- 笑点由节奏制造：Hold 越长，Deviation 越响。
- 符号化演出（COMEDY-SD/颜艺/汗滴/速度线）集中用在 Reaction 与 Punchline。
- 节奏：铺垫快、停顿长、反转突然、收尾干净。
- 15s 内 1-2 个完整笑点，勿堆砌。
