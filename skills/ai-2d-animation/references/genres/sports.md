# Sports 类型模板

核心：状态 → 观察 → 危机 → 蓄力 → 启动 → Key Pose → Contact → 结果 → 对手/队友反应。

## Beat 结构
1. 状态（state）：赛前/回合前的对峙
2. 观察（observe）：阅读对手/场地
3. 危机（crisis）：失分/被压制
4. 蓄力（setup）：集中/呼吸/预备动作
5. 启动（launch）：动作开始
6. Key Pose：决定性瞬间（定格帧）
7. Contact：接触/命中
8. 结果（result）：得分/失分
9. 反应（reaction）：对手/队友/观众反应

## 规则
- 球类运动必须明确：球的位置、轨迹、谁控制。
- 决定性瞬间用 SAKUGA + 冲击帧 + 速度线。
- 声音：球声/裁判哨/观众声分层。
- 比分/时间等视觉信息必须清楚（Scoreboard 特写）。
