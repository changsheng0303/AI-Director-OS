# Sci-Fi 类型模板

核心：强调空间、材质、光源、科技界面和尺度。

## Beat 结构
1. 科技环境建立（tech establish）：界面/光源/材质先出场
2. 人类尺度对照（human scale）：角色与科技环境的对比
3. 系统规则（system rule）：科技能力边界展示
4. 故障/威胁（failure/threat）：系统异常
5. 对抗/利用（counter）：角色利用规则求生
6. 代价（cost）：科技运用的后果

## 规则
- 视觉奇观仍然服务剧情：每处特效必须承担信息/情绪/空间认知之一。
- 科技界面是"信息释放"的道具（见 story-craft.md §4 信息释放表）。
- 大尺度（飞船/城市）用 EW/WS，细节用 ECU 形成节奏对撞。
- 光效集中在故障/爆发点，日常保持冷色工业光。
