# Romance 类型模板

核心：距离 → 观察 → 发现 → 停顿 → 微表情 → 靠近/回避 → 误会/打断 → 余韵。

## Beat 结构
1. 距离建立（distance）：两人空间距离=心理距离的视觉化
2. 观察（observe）：一方看另一方的视线/角度
3. 发现（discovery）：注意到细节（眼神/动作/道具）
4. 停顿（beat hold）：关系变化前的静止帧
5. 微表情（micro-expression）：脸红/躲闪/抿嘴/眼神变化
6. 靠近/回避（approach/avoid）：身体动作表达心意
7. 误会/打断（interruption）：意外打断张力
8. 余韵（afterglow）：关系新状态的结尾定格

## 规则（story-craft.md §2 情绪阶梯）
- 情绪阶梯：觉察→犹豫→软化→默许→情动，每个跳级点必须有过渡节拍。
- 身体接触必须晚于默许信号（对视/放松）。
- 关系前史必须在开场 3 镜内传达（见 story-craft.md §1）。
- 距离是 romance 的镜头语言母题：越近越亲密，打断=距离重置。
- 亲密 setup 见 shots-library.md §5-6（Eye Contact → Push to Talk → Close Faces）。
