# Fantasy 类型模板

核心：先建立尺度，再展示角色。

## Beat 结构
1. 世界尺度建立（environment reveal）：环境/光/粒子/风/布料先出场
2. 角色进入世界（character entry）：角色与环境互动
3. 规则展示（world rule）：力量/魔法/能力的运作方式
4. 冲突触发（conflict trigger）：与世界的对抗
5. 高潮（climax）：力量释放/觉醒
6. 余韵（aftermath）：世界回归平静但已改变

## 规则
- 环境、光、粒子、风、布料等应帮助观众感知世界规则，而非装饰。
- 力量展示必须有"代价/限制"线索（防止玛丽苏）。
- 觉醒/释放用 SAKUGA 集中（10-20% 镜头）。
- 情绪阶梯：好奇→敬畏→理解→抗争→释放→沉淀。
