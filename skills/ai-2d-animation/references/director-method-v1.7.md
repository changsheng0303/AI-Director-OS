# Director Method V1.7

## 导演决策优先级
`Dramatic Intent → Blocking → Audience Information → Spatial Geography → Coverage → Framing → Camera Movement → Lighting → Style`

不要反过来从“漂亮构图”推剧情。

## Shot-as-Decision
每个 Shot 必须写一句：
> “这一镜让观众比上一镜多理解/感受到/期待了什么？”

## Blocking Before Framing
先确定：
- 谁在空间哪里
- 谁朝哪里移动
- 谁看谁
- 动作起点与终点
- 道具如何被使用
- 哪个空间锚点证明位置

再决定：
- 景别
- 角度
- 焦段感
- 镜头运动

## Coverage Ladder
默认：
`ORIENT → RELATE → ACT → REACT → CONSEQUENCE`

但根据 Scene Archetype 改写：
- Discovery：`ORIENT → CLUE → OBSERVER REACTION → REVEAL`
- Confrontation：`RELATE → POSITION → TACTIC → RESISTANCE → CHOICE`
- Pursuit：`ORIENT → TARGET → MOVE → OBSTACLE → CONTINUE`
- Comedy：`SETUP → EXPECTATION → MISDIRECT → PAYOFF → REACTION`
- Sports：`GEOGRAPHY → INTENT → PREP → IMPACT → RESULT → OPPONENT REACTION`

## Cut Motivation
每次 Cut 至少满足一种：
`information / reaction / action continuation / spatial clarification / rhythm / contrast / reveal`

如果只能回答“更电影感”，则不通过。

## Double-Contrast Rule
只有当两个镜头之间保留至少一个稳定锚点时，才允许同时改变两个以上维度（景别+空间、角度+运动等）。

## Repair Ladder
生成失败时按成本从低到高：
1. 重写动作顺序
2. 锁定 Start/End State
3. 修空间锚点
4. 降低镜头复杂度
5. 拆分 Shot
6. 更换 Coverage
7. 最后才重写 Prompt

## Director Review
Director 只做：PASS / FAIL / ISSUE CODE / FIX TARGET。
禁止在 QA 阶段偷偷改变 Story Contract。
