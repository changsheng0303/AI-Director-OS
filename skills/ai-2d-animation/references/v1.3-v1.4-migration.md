# V1.3 → V1.4 Migration

## 必增
- narrative_camera_version: v1.4
- camera_necessity_score: {information, emotion, spatial}
- visual_motif（复杂场景建议）
- primary_motion
- trigger
- end_state_link

## 兼容
旧 Shot Contract 没有这些字段时：
- camera_necessity_score 默认由 `camera_necessity` 推断；
- visual_motif 默认 `none`；
- primary_motion 从 `action` 提取；
- trigger 从 `beat` 或 `action` 提取；
- end_state_link 从 `continuity_out` 提取。

内容安全章节保持原版本不变。
