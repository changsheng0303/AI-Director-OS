# V1.2 → V1.3 Migration

V1.3 在不破坏既有生产链的前提下增加 Narrative Camera Logic。

## 新增 Shot 字段
- visual_question
- audience_knowledge
- character_knowledge
- information_withheld
- reveal_point
- emotional_landing
- camera_strategy
- camera_logic
- camera_necessity

## 迁移规则
1. 普通镜头：补齐信息与情绪字段；没有信息悬置时 `information_withheld=none`。
2. Reveal：必须补 `reveal_point`。
3. Withhold / Misdirect / Recontextualize：必须存在真实的隐藏信息。
4. 无叙事必要性的运镜：`camera_necessity=none`，并优先改 Static。
5. 旧项目的资产、Continuity、Budget、Agent Handoff 不需要重建，只需升级 artifact version。
