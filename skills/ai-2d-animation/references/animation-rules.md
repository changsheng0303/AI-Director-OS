# 2D Animation Grammar V1.2 — 通用动画原理

本文件是**所有演出类型共用的动作底层**（anime-grammar.md §6 的六种 Anime Treatment 都构建在这套原理之上）。写任何动作前先过一遍本节；写动作后对照本节验收。

---

## 1. 核心立场

1. 2D 动画是设计语言，不是写实摄影的卡通滤镜。
2. 每镜头先明确观众获得的信息，再决定构图与运动。
3. 动画的本质是**时间 + 间距**（Timing & Spacing）：同样两帧之间，位置变化决定快慢、快慢决定情绪。

## 2. 动作结构模板（三大模板）

| 模板 | 结构 | 适用 |
|---|---|---|
| 普通动作 | `Anticipation（预期）→ Action（动作）→ Follow-through（跟随）` | 日常、表演、大部分戏 |
| 高能动作 | `Setup → Hold → Burst → Impact → Recovery` | 战斗、爆发、关键瞬间 |
| 情绪动作 | `Intention（意图）→ Pause（停顿）→ Release（释放）→ Reaction（反应）` | 表情戏、内心戏 |

任何动作若套不进以上模板，说明它还没被想清楚。

## 3. 关键帧体系

| 帧型 | 定义 | 作用 |
|---|---|---|
| Key Pose（关键帧） | 动作意图最清晰的姿态 | 定义"在做什么" |
| Extreme（极限帧） | 动作到达最夸张的端点 | 定义"做到多满" |
| Breakdown（过渡帧） | 连接两个 Key 的中转姿态 | 定义"怎么拐过去"（弧线关键） |
| In-between（中间帧） | 平滑填充帧 | 决定 Spacing 与流畅度 |

**原则**：先定 Key → 再定 Extreme → 再补 Breakdown → 最后 In-between。AI 视频生成中，Key/Extreme 对应"首尾帧策略"，Breakdown 对应"关键动作提示"。

## 4. Timing & Spacing（时间与间距）

- **Timing 决定"有多快"**：帧数越多动作越慢、越稳、越有重量。
- **Spacing 决定"怎么快"**：同样 10 帧，均匀 = 匀速；前疏后密 = 加速；前密后疏 = 减速。

### Spacing 五型（含 Prompt 写法）
| 型 | 描述 | 情绪 | Prompt 写法 |
|---|---|---|---|
| Ease In | 逐渐加速 | 启动、蓄力 | "accelerating motion, ease-in" |
| Ease Out | 逐渐减速 | 停止、落地 | "decelerating motion, ease-out" |
| Constant | 匀速 | 机械、平移 | "constant speed" |
| Sudden Burst | 突然爆发 | 冲击、惊吓 | "sudden burst, sharp acceleration" |
| Stop-and-Hold | 骤停+保持 | 定格、惊愕 | "abrupt stop, hold" |

## 5. 运动规律（动漫适配版）

1. **慢入慢出（Ease In/Out）**：绝大多数自然动作起止渐快渐慢；只有机械、爆炸、笑点才用匀速或骤变。
2. **弧线运动（Arcs）**：肢体端点走弧线而非直线——直线=机器人，弧线=生命感。关键在 Breakdown 帧的落点。
3. **重叠动作（Overlap）**：附属物（头发/衣摆/尾巴/耳朵）滞后于主体运动 1-3 帧，到位后还有余振。
4. **跟随与拖尾（Follow-through）**：动作结束后附属物继续摆动至静止；摆动幅度逐帧衰减。
5. **次要动作（Secondary Motion）**：强化主体情绪（如握拳时肩膀微沉），**不抢主体**。
6. **挤压与拉伸（Squash & Stretch）**：弹性夸张——压缩蓄力、拉伸释放。比例保守（1.05-1.2）为正剧，1.3+ 为喜剧/SD。
7. **重量与体积（Weight）**：重心越低越稳；起跳先下沉、落地先缓冲；重物慢启动慢停止。
8. **预期（Anticipation）**：动前先反方向微动（后仰再前扑、收拳再出拳），让观众预知。
9. **夸张（Exaggeration）**：动漫允许超过物理真实的表达，但**只夸关键瞬间**，日常保持可信。
10. **吸引力（Appeal）**：姿态清晰可读——剪影（silhouette）能看懂动作，即 Appeal 合格。

## 6. Pose-to-Pose vs Straight Ahead

- **Pose-to-Pose**：先定关键姿态再补中间帧 → 姿态清晰、节奏可控 → **AI 视频默认**（对应首尾帧+关键动作）。
- **Straight Ahead**：从头画到尾 → 自然流畅、不可控 → 适合长连续运动（奔跑、打斗连段）。
- 混合：主体 Pose-to-Pose，附属物（头发/衣摆）Straight Ahead 自然摆动。

## 7. Hold 与停顿

- Hold 是**表演与剪辑工具，不是空帧**。
- 有效 Hold：信息被观众消化 → 1-2 拍（约 0.5-1s）刚好；情绪重场可到 3 拍。
- 停顿（Pause）优先于减速：喜剧的停顿=预期，正剧的停顿=重量。

## 8. 能量管理

1. 高潮与日常必须存在**能量对比**（密度/速度/帧数落差）。
2. 作画爆发（Sakuga）只给 10-20% 的关键镜头（见 anime-grammar.md §3）。
3. 每段戏至少安排一个"呼吸位"（静止/空镜/低信息镜头）让观众恢复注意。
4. 镜头运动必须有叙事理由，禁止连续炫技。

## 9. 声音与动画的咬合

- 声音不是后补标签：预期段配"吸气/蓄力音"，爆发段配"冲击音"，余韵段配"余响"。
- 打击感 = 动画冲击帧 + 声音爆发 + 剪辑硬切三者同帧。
- 重要动作至少考虑：对白/呼吸、环境声、动作声、音乐节拍、静音留白中的一种。

## 10. AI 生成执行适配

1. **首尾帧优先**：复杂动作写清起始 Key Pose 与结束 Key Pose，中间交给模型。
2. **有限动画约束**：MOTION 段声明"哪些在动、哪些静止"（static background + local motion）。
3. **拆分复杂动作**：一个镜头只承担一个主要动作；多段连招拆成多镜（见 SKILL.md §4）。
4. **夸张参数化**：把"很有冲击力"写成 `smear + impact frame + speed lines + white flash` 等可见元素。
5. **验收对照**：起点/终点/方向/重心/因果/关键帧六项不清，一律不入生成（见 Shot QA）。

## 11. 动画化检查清单（快速过一遍）

- [ ] 动作套得上三大模板之一？
- [ ] Key Pose 与 Extreme 已区分？
- [ ] Spacing 是哪种？Ease In/Out 还是 Burst/Hold？
- [ ] 附属物有 Overlap/Follow-through？
- [ ] 弧线还是直线？（直线需有理由）
- [ ] Squash & Stretch 幅度与演出类型匹配？（正剧保守、喜剧放开）
- [ ] 重量感：起沉、缓冲、重心清楚？
- [ ] 剪影可读？（Appeal 检查）
- [ ] 能量对比存在？（Sakuga 只给关键镜头）
- [ ] 声音与动画咬合？（冲击帧=声音爆发=硬切同帧）
