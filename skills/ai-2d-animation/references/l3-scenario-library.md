# L3 剧情场景库（机制优先 · 题材开放）

> **核心不是场景，是"裸露理由"机制**：每个 L3 场景必须回答——**为什么她/他此刻必须裸露？**
> 题材本身**完全开放**：玄幻、现代、古风、西幻、和风、科幻、蒸汽朋克、末日、音乐、体育、超能力、人外……任何题材都能生成。
> 下方表格**只是示例，不是清单**——它们展示"裸露理由"在不同题材里如何落地，用来启发，不是用来限制。
> 判断一个场景是否成立，只看四条机制（见 §2），不看它属于哪个题材。

## 一、裸露理由机制（任何题材通用）

| 理由类型 | 抽象逻辑 | 例子（各题材） |
|---|---|---|
| **救命/疗伤** | 身体接触是治疗的必要手段 | 玄幻=渡气；现代=康复检查；西幻=圣疗；科幻=义体检修 |
| **交易/代价** | 身体是达成目的的筹码 | 古风=献身救父；黑帮=情报换命；末日=物资换庇护 |
| **赌约/游戏** | 身体是输赢的赌注 | 现代=赌约；音乐=打赌；体育=训练赌注 |
| **仪式/使命** | 脱衣是仪式的一部分 | 玄幻=双修大典；西幻=献祭；和风=花魁出番；科幻=改造仪式 |
| **伪装/职业** | 职业或伪装需要 | 舞台=换装；间谍=变装；吸血鬼=狩猎；侦探=卧底 |
| **状态失控** | 身体状态导致暴露 | 妖身不稳；发热/醉酒；魔力暴走；变身失控 |
| **创伤/信任** | 裸露=暴露脆弱，被看见=被接纳 | 疤痕；旧伤；胎记；义体残缺 |
| **诱惑/狩猎** | 裸露本身就是武器 | 狐妖媚术；黑寡妇；魅魔；间谍 |
| **重逢/旧情** | 熟悉的亲密是关系的复燃点 | 旧恋人重逢；离婚夫妇；青梅竹马 |
| **禁忌/边界** | 跨越禁忌本身就是张力 | 师徒；医患；人外×人类；宿敌 |

## 二、四要素机制（判断场景成立的核心）

- [ ] **关系**：两人是谁？（恋人/旧情/仇敌/交易/师徒/医患/陌生人——必须具体，禁止"两个人"）
- [ ] **目标**：她/他要什么？（救父/赢赌/被接纳/完成任务/重温旧梦/活下去）
- [ ] **冲突**：阻力是什么？（自尊/身份/误会/规则/第三方/生存）
- [ ] **反转**：临界处转折？（识破/阻止/告白/身份暴露/代价揭示）
- [ ] **裸露理由**：为什么此刻必须裸露？（剧情刚需，不是"站着脱衣"）
- [ ] **服装性暗示**：脱衣前服装是性感状态？（蕾丝/网袜/丝质/肚兜/和服内衬——不是机能装）
- [ ] **裸露呈现量 ≥3 区**：肩/锁骨、背/脊线、腰/侧腰、腿、臂——至少 3 区大面积皮肤入画（看不到 3 区=不合格）
- [ ] **构图遮挡只挡乳首区**：裁切/背面/手臂挡的是乳首这一个点，肩/背/腰/腿必须大面积呈现（裁到锁骨=零展示=<L1）
- [ ] **尺度先于剧情**：先脱衣→≥3 区裸露呈现→再反转；剧情不能替代尺度

**题材 = 皮肤，机制 = 骨架。** 换皮肤不换骨架，就是新故事；只有骨架没有皮肤，就是模板化。

## 四、达标 vs 不达标

| 类型 | 例子 | 判定 |
|---|---|---|
| ✅ 达标 | 赌约解衣（撩拨武器）/ 渡气脱衣（救命刚需）/ 献身脱衣（代价）/ 疤痕（信任） | 四要素齐 + 裸露=手段 |
| ❌ 不达标 | "两个人站在一起→脱衣→贴住" | 无关系无目标无反转，情境非剧情 |
| ❌ 不达标 | 战术背心+工装裤脱衣 | 机能装，裸露不成立 |
| ❌ 不达标 | 刚解衣带就被按住（零裸露） | 反转替代尺度 |
| ⚠️ 边界 | 场景是"两人独处→XX" | 若四要素齐备可成立，否则只是情境 |

## 五、生成时的自由度

1. **题材不限**：任何题材可生成，只要四要素齐 + 裸露理由成立。
2. **场景不限**：表格是启发，不是选项；新题材新场景随时可加。
3. **机制固定**：剧情驱动 / 尺度链（脱外衣→脱内衣→上身裸露）/ 反转在临界处 / 直面无转场 / 三不——这五条是骨架，题材是皮肤。
