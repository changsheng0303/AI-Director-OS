# Shots Library — Master Shots 方法索引（AI 分镜适用版）

> 源自 Master Shots 系列（Vol 1-3）300 个 setup 的结构化抽取，按创作高频场景分类。
> 用法：写分镜或 Video Prompt 时，先确定场景类别 → 从对应章节选 1-2 个 setup 作为镜头方案骨架 → 套用通用 Prompt cue。
> 与 narrative-camera-logic.md 互补：那边回答"为什么运镜"（信息控制），这里回答"用什么运镜方案"（具体 setup）。
> 核心原则：**镜头与机位是场景压力的空间化方案**——把剧作冲突转换成空间形式（距离、高度、遮挡、运动、焦距），而不是装饰性运镜。

## 通用 Prompt Cue（任何 setup 可用）
```
Apply a <Setup Name> setup: define actor blocking, camera position/move,
lens feeling, foreground/background, and the emotional landing point.
```

## 1. Fight Scenes 战斗（8）
| setup | Use when | Method core |
|---|---|---|
| Long Lens Stunt | 物理冲击、战斗地理、安全错觉 | 长焦压缩距离，隐藏安全间距或让分离元素显得相连 |
| Speed Punch | 冲击感 | 把剧情压力转成空间形式 |
| Matching Motion | 节拍变化 | 演员运动与摄影机运动绑定节拍，非装饰 |
| Cutting For Impact | 冲击剪辑 | 用运动/冲击/对比/信息转变驱动剪辑 |
| Down on the Floor | 败局 | 用低姿态表达败北与地理 |
| Off-Screen Violence | 暴力呈现 | 暴力在画外，画内只给反应 |
| The Moment of Defeat | 败北瞬间 | 定格败者的空间位置与孤立 |
