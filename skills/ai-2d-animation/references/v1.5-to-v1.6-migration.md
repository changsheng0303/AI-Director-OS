# V1.5 → V1.6 Migration

## 核心问题
V1.5 已经解决“镜头之间跳脱”，但 Prompt/Storyboard 仍可能把每个短片段写成一个小型电影结尾，常见结果是：熄灯、淡黑、剪影、拉远、空镜、雨景、背影离开。

## V1.6 解决
1. 增加 Ending Architecture。
2. 区分 Clip Landing / Scene Exit / Sequence Resolution。
3. 增加 Ending Function、Exit State、Ending Reason。
4. 增加 Ending Anti-Cliche Gate。
5. Prompt Compiler 不得自行发明结尾。
6. Storyboard Artist 先锁状态再写最后一帧。
7. 增加 Ending Contract Schema。

## 迁移原则
- 保留 V1.5 的 Story Contract、Beat Chain、Shot Adjacency、Spatial Continuity。
- 不修改内容安全章节。
- 已有 Shot 没有 ending_function 时，按上下文补最小合理类型，不自动使用 fade/dim。
