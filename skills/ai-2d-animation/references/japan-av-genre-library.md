# 日本 AV 题材全谱（创作参考库 · V1.7）

> 来源：日本成人视频（JAV）行业类型学 + 日本《刑法》175 条马赛克审查制度研究。
> 用途：为 L3 剧情创作提供**题材灵感库**——每个题材给出核心张力、可转化的剧情逻辑、生产状态。
> **执行边界（用户已授权）**：本库完整收录日本 AV 全谱题材；但**执行时由模型把关**——标注「⛔ 不生产」的题材（非自愿/未成年等）永不生成，用户要求过分时可拒绝并说明。素材库完整性 ≠ 生产授权，创作自由与执行边界分开。

## 0. 日本 AV 的核心特征（先理解行业逻辑）

1. **马赛克审查制**：日本《刑法》第 175 条禁止露骨展示——所有合法 AV 必须打码生殖器（动画/游戏同规）。→ 与 skill 三不原则同一逻辑：**限制催生表达**。
2. **题材即标签**：日本 AV 用"标签系统"（ジャンル/タグ）组织作品——一部片子挂多个标签，题材细分到极致。
3. **剧情化倾向**：日本 AV 比欧美更重视"情境设定"（シチュエーション），纯动作片也会给"情境包装"——**这正对应 skill 的"裸露理由机制"**（为什么此刻必须裸露）。

## E. 日本审查制度对创作的启示（与 skill 对应）

| 日本制度 | skill 对应 |
|---|---|
| 175 条马赛克（生殖器必码） | 三不原则（生殖器/乳头/臀部）——同源逻辑 |
| 阴毛曾禁（1990s 前） | 遮挡物开放（发型/光影/道具） |
| 肛部仅在接触/插入时码 | 臀部必遮（内裤/床单/裁切） |
| 情境包装（シチュエーション） | 裸露理由机制（为什么此刻必须裸露） |

## F. 执行边界声明（用户已授权 · 模型把关）

1. **⛔ 永不生产**：未成年性化（萝莉/正太/童颜）、非自愿（痴汉/凌辱/暴力/洗脑）、真实犯罪美化。
2. **⚠️ 边界内可做**：需成年角色 + 知情同意框架 + 三不原则 + 剧情驱动四要素。
3. **拒绝权**：用户要求越过边界时，模型可选择不生产并说明理由——用户已明确同意此规则。
4. **素材库完整性 ≠ 生产授权**：本库收录全部题材供创作参考，但生产与否由执行层把关。
