# 风格预设：Lineless Flat 无线纯色风（无描边色块插画）

> 核心哲学：**形状靠色块边缘与明度对比区分，不靠线条**。画面中没有一根描边线——边缘即色块的边界。
> 类似现代扁平插画 / 剪纸拼贴 / 部分韩系动画背景的简化版。与"罗小黑极简线稿风"互为两极：一个有线，一个无线。

## 视觉语言五要素（项目级锁定）

| 要素 | 设定 | Prompt 写法 |
|---|---|---|
| **线稿 Lineart** | **无（lineless）**——画面不存在描边，形状完全靠色块边缘 | `lineless flat illustration, no outlines` |
| **上色 Coloring** | 纯色块平涂，块与块之间直接贴边；可少量同色系色块堆叠表示立体 | `solid flat color blocks with clean edges` |
| **阴影 Shading** | **色块阴影**：阴影 = 独立色块（暗一档的同类色）叠在下方，不是渐变也不是模糊 | `hard-edged block shadows in darker tones` |
| **高光 Highlight** | 极少或不用；需要时用纯白色块（如眼神光圆点） | `minimal pure-white accent blocks` |
| **质感 Texture** | 完全光滑、无颗粒；可带轻微剪纸/贴纸边缘感 | `clean smooth texture, paper-cut edge feel` |

## 形状语言（lineless 的关键）

- **边缘必须清晰**：色块与色块之间用明度差/色相差分隔，相邻形状必须有足够对比，否则会糊成一片。
- **留边技巧**：深色主体放浅色底、浅色主体放深色底；相邻同明度色块之间垫一层中间色或留白。
- **立体感靠色块堆叠**：一个物体的体积用 2-3 个色块（亮/中/暗）叠加表达，不用渐变。
- **背景简化**：背景通常 2-4 个大色块（天空/地面/远山），装饰元素用几何形状。

## 色彩系统

- 饱和度灵活：高饱和版 = 撞色冲击（红×黄×蓝）；低饱和版 = 温柔扁平（莫兰迪）。
- 默认推荐**高纯度高饱和**（用户偏好）：色块之间撞色，明度拉开。
- 配色通常 3-5 色限制，保持"色块感"不脏。

## 适用场景

- 角色立绘/头像/海报（扁平感强）
- 装饰性插画、LOGO 风、UI 插画
- 想要"现代/简洁/设计感"的镜头

## 一句话锁定写法

```
lineless flat illustration, no outlines, solid flat color blocks with clean
paper-cut edges, hard-edged block shadows in darker tones, minimal pure-white
accent highlights, high-saturation bold color palette of 3-5 colors, clean
smooth texture, shapes separated by value contrast
```
