# Shot QA Checklist V1.2

## Contract
- [ ] Purpose 单一且明确
- [ ] Key Pose 可描述
- [ ] 起点/终点清楚
- [ ] Screen Direction 清楚
- [ ] 构图主体明确
- [ ] 运镜有理由
- [ ] 动作有因果
- [ ] Acceptance Criteria 可验证

## Story（story-craft.md）
- [ ] 本镜关系线索可被单帧读到（relationship_hint）
- [ ] 情绪变化有过渡节拍，无跳级
- [ ] 角色行为有动机来源（motivation）
- [ ] 身体接触晚于默许信号
- [ ] WITHHOLD 有对应 REVEAL

## NSFW Level（SKILL.md §13）
- [ ] 本镜 NSFW Level 已标注（0-4）
- [ ] Level 2+：遮挡手法已写在 Composition/Lighting/Audio（构图裁切/雾气/光影/道具/发丝）
- [ ] Level 3：三不原则遵守（乳头/臀部必遮、无完全裸露、不写学生身份涉性）
- [ ] 实际输出未超出目标 Level 边界

## Continuity
- [ ] Continuity In/Out 存在
- [ ] 角色位置/视线/方向承接
- [ ] 资产版本未漂移
- [ ] 道具状态承接
- [ ] 光向/时间/天气无无理由跳变
- [ ] 轴线变化有明确标记

## Anime / Generation
- [ ] Anime Treatment 与情绪匹配
- [ ] 情绪有可见视觉表达
- [ ] 有限动画约束已声明
- [ ] 视觉语言五要素未漂移
- [ ] 风险项有对应 Acceptance
- [ ] Budget Tier 合理

## Version / Repair
- [ ] Shot Version 正确
- [ ] 已通过变量已冻结
- [ ] 若为修复版本，有 Failure Code 与 Repair Delta
