# fantasy-sci-fi Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（SAKUGA + SYMBOLIC 向）**：奇幻/科幻的动漫化核心是「能量可视化」——魔力/能量流用速度线、光晕、粒子、变形表达；变身/启动用 Bank Shot（复用仪式镜头）+ 中心对称构图 + 白闪。世界尺度用空气感与背景层（云/星云）表达。

## fantasy-sci-fi-01 Scale Reveal
- Intent: 世界尺度
- Framing: EWS
- Camera: pull
- Animation: 宏观拉远 + 人物微小 + 大气透视 + 背景层缓慢流动（有限动画）
- Anime Treatment: **REALISTIC-ANIME** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
