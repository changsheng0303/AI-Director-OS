# cinematic Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（REALISTIC-ANIME 向）**：正剧镜头克制符号化，用构图/光影/运镜说话。动漫风味来自：空气感背景（大气透视）、逆光轮廓光、眼瞳高光、发丝/衣摆的 Secondary Motion。情绪重场允许一次符号化爆点（白闪/速度线）作为高潮标记。

## cinematic-01 Establishing Reveal
- Intent: 建立空间后揭示主体
- Framing: WS/EWS
- Camera: slow push
- Animation: 环境先静（LIMITED：云/水微动）→ 主体切入瞬间一次微push，配光线变化
- Anime Treatment: **REALISTIC-ANIME** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
