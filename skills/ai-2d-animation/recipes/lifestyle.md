# lifestyle Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（LIMITED + MOE 向）**：日常/空气系是有限动画的舞台——大量静止 + 局部微动（茶的热气、窗帘、发梢），生活噪音与光影变化承载时间感。情绪克制，符号化只在治愈/萌点出现（红晕、花瓣、猫嘴）。

## lifestyle-01 Ambient Establish
- Intent: 空气感
- Framing: WS
- Camera: static
- Animation: 环境静止 + 仅热气/云/光斑微动，空气感靠微动与光影时间变化
- Anime Treatment: **LIMITED** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
