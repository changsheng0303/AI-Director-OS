# suspense Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（LIMITED + SYMBOLIC 向）**：悬疑的动漫化核心是「信息的克制」——大量 LIMITED（静态、缓慢推镜、局部动）制造不安；符号化只用最克制的一种：阴影压眼、刘海遮眼（glare）、汗滴、屏息定格。声音先入（off-screen sound）比画面先到。",

## suspense-01 Partial Reveal
- Intent: 局部信息
- Framing: ECU
- Camera: slow pan
- Animation: 局部特写 + 缓慢横移 + 仅细节微动（滴水/电流），信息挤牙膏
- Anime Treatment: **LIMITED** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
