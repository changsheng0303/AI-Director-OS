# acting Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（MOE/SYMBOLIC 向）**：表演类镜头以 CU/MCU 为主，符号化情绪优先——害羞→红晕+侧脸回避、无语→豆豆眼、尴尬→汗滴。眼神高光（星形/月牙）与发丝动态是情绪放大器。有限动画：身体微动+眼睛/嘴/发丝动即可，背景静止。

## acting-01 Micro Reaction
- Intent: 微表情变化
- Framing: CU
- Camera: static
- Animation: 表情变化用符号化渐进：普通脸 → 汗滴出现 → 豆豆眼，全部为可见符号序列
- Anime Treatment: **MOE** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
