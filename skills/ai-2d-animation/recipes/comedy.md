# comedy Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（COMEDY-SD 向）**：喜剧核心是「预期→停顿→爆发」与「颜艺/SD化」。正常画风建立预期 → hold 停一拍 → 突发颜艺或 Q 版化（2 头身）制造落差。吐槽位（deadpan）+ 重复梗是节奏工具。符号系统全开：豆豆眼、猫嘴、汗滴、青筋、背景炸裂。

## comedy-01 Normal Setup
- Intent: 建立正常预期
- Framing: MS
- Camera: static
- Animation: 正常画风 + 正常节奏建立预期，刻意不搞笑（笑点的反差基础）
- Anime Treatment: **REALISTIC-ANIME** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
