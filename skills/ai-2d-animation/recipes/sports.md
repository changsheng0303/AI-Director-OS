# sports Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（SAKUGA + LIMITED 向）**：运动番的动漫化核心是「关键帧密度切换」——发球/击球瞬间用 SAKUGA（拉伸变形、冲击帧、速度线），读对手/准备阶段用 LIMITED（静态+眼神/呼吸微动）。比分冲击用符号化（白闪、速度线、球路轨迹线）。

- Intent: 发球/启动准备
- Framing: FS
- Camera: slow push
- Animation: 准备阶段：静态 + 仅呼吸/发丝微动 + 眼神锁定（山雨欲来的静）
- Anime Treatment: **LIMITED** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
