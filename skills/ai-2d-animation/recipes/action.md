# action Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（SAKUGA 向）**：动作戏核心是「蓄力→爆发→冲击→回收」的能量结构。拉伸变形（smear）、冲击帧、极限透视、速度线集中用在爆发与命中瞬间；运动期间角色动、背景用速度线或静止背景制造对比。Sakuga 镜头占比 10-20%。

- Framing: FS
- Camera: static
- Animation: 压缩蓄力帧：身体压低 + 地面裂纹 + 速度线预兆 + 慢速吸气音
- Anime Treatment: **SAKUGA** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
