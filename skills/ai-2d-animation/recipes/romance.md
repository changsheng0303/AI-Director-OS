# romance Shot Recipes V1.2

每个 Recipe 使用：Intent → Default framing → Default camera → Animation idea → Anime Treatment → Adaptation notes。


> **类型演出惯例（MOE + REALISTIC-ANIME 向）**：恋爱镜头的动漫化核心是「距离与微表情」——慢推、光斑/花瓣、心跳音效、视线交错。害羞用红晕+侧脸+发丝遮挡；心动用眼瞳高光+背景虚化+樱花/光斑。Level 2+ 暧昧场景：光影/构图/肢体替代符号化夸张（anime-grammar §8）。

## romance-01 Distance Establish
- Intent: 建立两人空间距离
- Framing: WS
- Camera: static
- Animation: 两人距离用空间构图表达 + 中间留白（负空间即情感距离）
- Anime Treatment: **REALISTIC-ANIME** — 见动画语法与符号系统（anime-grammar.md）
- Adaptation: 必须结合角色目标、场景关系、前后镜头与连续性重新设计。
