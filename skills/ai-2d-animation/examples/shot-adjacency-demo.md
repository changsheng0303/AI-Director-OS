# Shot Adjacency Demo V1.5

| Shot | Type | Start | Main Change | End | Bridge |
|---|---|---|---|---|---|
| 01 | ESTABLISH/CONTINUE | 女主从左进入雨街 | 走到咖啡馆窗前 | 女主停在窗外 | movement |
| 02 | REACT | 延续窗前停步 | 眼神转向玻璃 | 视线锁定室内 | gaze |
| 03 | REVEAL | 视线仍指向玻璃 | 男主被看见 | 男主仍未知 | gaze match |
| 04 | CONTINUE | 女主看着男主 | 手接近玻璃 | 指尖停在一厘米外 | action match |
| 05 | REACT | 男主仍坐在窗边 | 听到/感到异样并抬头 | 看向同一窗 | reaction |
| 06 | REVEAL | 男主看向窗 | 发现窗外为空 | 只剩自己的倒影 | spatial reveal |
| 07 | RECONTEXTUALIZE | 空玻璃 | 唇印出现并消退 | 男主手按玻璃 | prop/trace |
| 08 | SCENE_BREAK | 男主仍在室内 | 冲出门 | 街角伞消失 | movement + cut |

核心：每一镜不是“另一个漂亮画面”，而是上一镜状态的下一步。
