# Narrative Camera Demo V1.3

## 场景：《最后一班电车》

目标：测试 Skill 是否能够用镜头控制观众信息，而不仅是堆砌摄影术语。

### 信息结构
- 角色知道：她在等一个重要的人。
- 观众知道：她在等待，但不知道对象是谁。
- 有意隐藏：站在她身后的“人”是否真实存在。
- 误导：女孩转身后露出安心的微笑，让观众暂时相信她等到了。
- 揭示：通过静态空间重新构图，证明女孩其实一直独自一人。
- 再语境化：广告牌上的旧照片解释前面镜头中的视觉信息。

### 推荐 Shot Logic
1. `ESTABLISH` — 极宽静态，建立孤独空间。
2. `OBSERVE` — 特写车票，让道具承担情绪信息。
3. `ALIGN` — 反应近景，与女孩视线对齐但不揭示对象。
4. `WITHHOLD` — 越肩镜头，保留画外信息。
5. `REVEAL` — 缓慢 Pull Back，通过空间揭示身后人物。
6. `MISDIRECT` — 女孩微笑并走向人物，保持观众判断。
7. `RECONTEXTUALIZE` — 切到另一侧，证明她独自一人，再露出广告牌。
8. `RELEASE` — 最终远景，让情绪沉降。

### 导演测试标准
- 每个镜头都有明确的信息任务。
- 运镜删除后若不损失信息、情绪或空间认知，应改为 Static。
- Reveal 必须改变观众对前面镜头的理解。
- Misdirect 必须有后续重新解释。
- 最终镜头不依靠台词解释，而依靠空间、道具和构图完成意义。
