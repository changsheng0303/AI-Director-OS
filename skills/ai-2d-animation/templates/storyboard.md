## 填写规则
- `Version`：`v001` 起，每次批准变更递增。
- `Visual Question`：镜头希望观众主动观察/思考什么。
- `Audience Knowledge` / `Character Knowledge`：明确双方信息差。
- `Information Withheld`：没有隐藏信息时写 `none`；有意悬置时必须具体说明。
- `Reveal Point`：写清信息通过何种视觉动作、构图或剪辑揭示。
- `Emotional Landing`：镜头结束时观众应落入的情绪。
- `Camera Strategy`：描述控制信息的总体摄影策略，而非堆砌摄影术语。
- `Camera Logic`：ESTABLISH / OBSERVE / WITHHOLD / ALIGN / ESCALATE / REVEAL / MISDIRECT / RECONTEXTUALIZE / CONTRAST / RELEASE。
- `Camera Necessity`：information / emotion / spatial_understanding / none。若为 `none`，默认 Static。
- `Screen Direction`：明确 left→right / right→left / static / radial 等。
- `Continuity In/Out`：必须写可供前后镜头继承的状态。
- `Risk`：只写真实生成风险，不把普通描述当风险。
- `Acceptance`：必须可观察、可验证。
- `Budget`：L / M / H / HERO。
- `Anime Treatment`：REALISTIC-ANIME / SYMBOLIC / LIMITED / SAKUGA / COMEDY-SD / MOE。
- `Coverage`：covered / intentional_repeat / omitted_with_reason / nonvisual_context。
- `Duration`：数字秒数；总时长由 Validator 检查。
- `NSFW Level`：每镜标注 0-4（见 SKILL.md §13.1）；Level 2+ 必须在 `Composition/Lighting/Audio` 中写明遮挡手法（构图裁切/雾气/光影/道具/发丝）；Level 3 遵守三不原则（乳头/臀部必遮，无完全裸露）。
