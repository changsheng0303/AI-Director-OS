# 台词七维诊断（Dialogue Seven-Dimension Diagnosis）

> 来源：台词专家方法论增量提取（2026-08 融合）
> 用途：对剧本台词逐句诊断——哪里不对、怎么改、为什么改
> 触发：用户要求"诊断台词/台词改一下/这句话怪怪的"，或 S1.5 台词 QA
> 铁律：**每条修改建议必须包含"为什么这么改"，无理由的修改禁止输出**

## 七维诊断框架（按顺序过）

### 维度1：角色辨识度（Voice Print）
- 核心拷问：遮住角色名，能不能认出谁在说？
- 检查：词汇库（专属高频词/禁用词）、句长偏好、句式习惯（反问/感叹/陈述）、口头禅/语气词、文化层（教育/地域/年代）
- 红线：A 角色的台词换给 B 说毫无违和 = 严重不及格
- 典型病症：全员播音腔、主角配角同修辞密度、师傅徒弟同现代语

### 维度2：潜台词层级（Subtext）
- 核心拷问：字面说的，是不是真意？有几层？
- 层级：直白=0层；说反话=1层；行为目的与言说目的错位=2层；多层人物关系折射=3层
- 红线：所有台词都是0层（想什么说什么）= 像 AI 写的而非戏
- 典型病症："我很愤怒"（应写动作+反话）、"我必须救你，因为你是我哥"（应埋动作里）

### 维度3：冲突推进力（Conflict Drive）
- 核心拷问：这一句让张力前进了，还是原地踏步？
- 检查：每句后至少一项变化（信息/立场/关系/情绪温度/下一步动作）；回合感（两人持球互攻 vs 单口相声）；反向力（"不"/"但是"/"可是你忘了"）
- 红线：连续3句以上没推进任何东西 = 该删
- 典型病症：寒暄过长、双方重复彼此论点、解释性对白（向观众讲设定）

### 维度4：类型语感（Genre Voice）
- 核心拷问：这句话在这个类型里成立吗？
- 古装/武侠：避免"OK/项目/效率"等现代词；现代都市：避免整段文言；悬疑：信息控制（说一半留钩子）；喜剧：反转错位，忌"陈述笑点本身"；年代戏：术语/物件/称谓匹配年代
- 红线：单句中混入跨类型违和词 = 立即标红

### 维度5：信息效率（Info Efficiency）
- 核心拷问：用最少的字传递最多的东西吗？
- 检查：反 exposition（不向观众塞设定）；一句多用（信息+性格+推进+潜台词 ≥2 项=优秀）；删字测试（去掉这句子剧情还成立吗）；替换测试（能用动作/表情/道具替代吗）
- 红线：连续两句"as you know"式设定灌输 = 重写
- 典型病症："你忘了吗，三年前我们就是在这里……"、自报家门、旁白替角色说心理

### 维度6：（补充维度，源自用户已有写作红线）
- 无心理描写：禁止"他意识到/她想起/内心涌起"，只写镜头能拍到的动作
- 无括号暗示：禁止"（悲伤地）"式表演指示，动作写到位演员自然会懂
- 动作即潜台词：每个动作必须有指向性

### 维度7：（补充维度，源自用户已有红线）
- 台词口语化：短句、语气词、留白、打断；拒绝书面腔和解释性台词
- 角色语言区分：结合维度1，每个角色 1-2 个独占语言标记（称呼/语气词/句式）

## 诊断流程

1. **全量盘点**：逐句过七维，输出诊断表（原台词 → 问题维度 → 问题说明）
2. **重点开刀**：只改写命中≥2维问题的台词，其余不动
3. **每改必给理由**：违反了哪几维 + 改后命中了什么
4. **不做的事**：不重写整剧、不改剧情结构、不评判故事内核（那些回 S1/S1.5）

## 输出契约（每条修改建议三段式）

```markdown
原台词：____
改写后：____
为什么：违反了[维度X]（说明）→ 改后命中[维度Y]（说明）
```

## 专项任务

| 指令 | 输出 |
|---|---|
| 角色辨识度矩阵 | 全员"语言指纹对比表" |
| 金句生成 角色=X 场=Y | 3-5 条候选金句（仍附理由） |
| 潜台词标注 | 每句标潜台词层级（不改写） |
| 节奏诊断 | 只看长短句/停顿/语气词分布 |
| 重写台词 场=X | 七维扫描后给整段重写版 |

## 与 V4.0 系统的挂接

- 产出落点：S1.5 Creative Audit Package → `dialogue_qa: [{line, issue_dims, rewrite, reason}]`
- 触发路由：S1.5 台词 QA / drama-script-iteration 改稿时叠加
- 校验：无 reason 的修改建议 = FAIL 打回
