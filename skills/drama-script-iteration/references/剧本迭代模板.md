# 剧本迭代模板（V7→V11 实践沉淀）

## 版本说明模板（新版本文件头部）

```
# 《剧名》V{版本号} {版本特征} EP1-EP{集数}

> **版本说明（V{版本号} 较 V{上一版} 的改动）**
> 1. {本轮改动1：改了什么、为什么}
> 2. {本轮改动2}
> N. 其余沿用 V{上一版}：{沿用项清单}
>
> **写作红线（沿用）**：无心理描写、无括号暗示、台词口语化、动作即潜台词、所有内容可从视听角度拍摄。
```

版本特征命名：V8四推强化版 / V9身份隐藏版 / V10过渡衔接版 / V11彩乃人设修正版。

## 四推行为系统表模板

```
### {角色名}（{年龄}·{定位标签}）
- **专属记忆点**：① {签名道具}；② {签名动作}；③ {签名台词}
- **说话方式**：{常态特征；形态切换时如何变（若双形态）}
- **行为逻辑**：{固定行为模式}
- **情绪反应**：{触发→反应，若干条}
- **×狗互动模式**：{不知情结构下与男主（宠物形态）的互动方式}
- **禁区**：{该角色绝不会做的事}
```

## 切片配额表模板

```
| 主推 | 切片 | 时长 | 位置 | 独立成片逻辑 |
（每主推 3 段 15-30s；独立成片逻辑=单剪出来零前情可看的理由）
> 附赠切片（不占配额）：{清单}
```

## 恋爱进度表模板

```
| 角色 | EP1 | EP2 | EP3 | EP4 | 弧线终点 |
| 每格写 Lv + 关键事件（如 "Lv2 日记真心话"）；未出场写 —（未出场）
```

## 过渡写法示例（六种类型）

| 类型 | 用法 | 示例 |
|------|------|------|
| 声音桥接 | 下一场景声音先入 | `[过渡·声音桥接] 心跳声渐隐，海浪声与校园铃声渐起。` |
| 空间移动 | 跟随角色位移 | `[过渡·空间移动] 悠太穿过操场，教学楼的阴影笼罩下来。` |
| 时间过渡 | 天色/光线变化 | `[过渡·时间] 夕阳把沙滩染成金色，人群散尽。` |
| 视角切换 | 切另一地点/人物 | `[过渡·视角切换] 同一时刻，学园保健室的灯还亮着。` |
| 光线过渡 | 门缝光/月光 | `[过渡·光线] 门缝里漏出台灯暖光，照亮狗竖起的耳朵。` |
| 闪回 | 时间回拨到某瞬间 | `[过渡·闪回] 时间回拨到浓烟炸开的瞬间——信封在气流里翻落。` |

## 不知情结构的"知情痕迹"检查点

- 台词出现"变身/第三次/确认/同一主体/就是它"等词 → 删或改写
- 日记/备忘录/补记出现"眼神好像他/完全重合/确认" → 改为"待查/待进一步验证/说不上来"
- 角色闪念 → 用"自我否定"处理（"……我在想什么啊。疯了吧。"）
- 最接近真相者 → 数据吻合但"缺证据不下结论"（如"证据不足。继续观察。"），留 EP 末悬念
- 最强反讽点："以为对方听不懂才说真心话"（如花穗对狗说"反正你也听不懂"）
