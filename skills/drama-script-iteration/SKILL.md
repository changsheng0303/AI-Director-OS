# 短剧剧本迭代 Skill

对用户已有的短剧/番剧剧本做版本迭代（V7→V8→V9…）的执行工作流。与「微短剧创作」（从零创作新剧本）和「红果审剧本」（审稿给建议）互补：本技能负责"在用户原文上动手改稿"。

## 触发场景

- 用户说"修改/优化/重写一下剧情"、"调整人设"、"加个过渡"、"这个设定不对"
- 用户引用已有剧本文件（desktop-attachments\*.txt / *.docx）要求改稿
- 剧本进入版本迭代，需要产出新版本文件

## 工作目录与版本管理

- 剧本存 `{当前工作区}\剧本\`，每版独立文件：`《剧名》V{版本号}{版本特征}.md`
- 版本特征命名示例：V8四推强化版 / V9身份隐藏版 / V10过渡衔接版 / V11彩乃人设修正版
- 每个新版本文件头部写【版本说明】：本轮改了什么、为什么、哪些沿用上版

## 铁律（用户硬性要求，违反必被打回）

1. **原文底本原则**：以用户提供的原文为底本。只允许修改"用户明确授权修改的部分"；其余场景/台词/切片/伏笔/结尾悬念一字不动。交付前逐段比对，确认没有越权改动。
2. **新增≠修改**：丰富内容只能用"加"（过渡、衔接、扩展段落），不能替换或改写原有内容。用户说"要在我给的剧情上加"＝加过渡衔接，不是重写。
3. **不添加设定外物品**：用户设定里没有的道具/设备/规则一律不加（教训：擅自加"电子项圈"被驳回"我的设定里没有"）。原文没交代的逻辑漏洞（如变身后心率表去哪了）宁可不交代，也不要发明新道具填补。
4. **段落过渡**：每段之间必须有画面衔接，格式 `[过渡·类型] 描写`。六种类型：声音桥接（下场景声音先入）、空间移动（跟随角色位移）、时间过渡（天色/光线变化）、视角切换（切另一地点/人物）、光线过渡（门缝光/月光）、闪回（时间回拨到某瞬间）。过渡只做衔接，不承担剧情、不引入新设定。
5. **角色-场景逻辑**：每轮改稿检查"角色身份 vs 出现场景"——校医只能出现在学校/保健室/球场等学园场景，不能出现在家庭场景（教训：EP2 彩乃走廊段因"校医怎么会在家里"被删）。任何角色出场前先问"她为什么在这里"。
6. **人设修改全表联动**：改一个人设必须同步更新：行为系统表、称呼/签名记忆点、所有相关切片台词、术语全局统一（如"柔形态"→"温柔形态"）、恋爱进度表、切片配额表、伏笔时间线。漏一项就是下一轮被打回的理由。
7. **反差形态触发要自然**：双形态角色（彩乃式：甜食→温柔，酸→复位懒散态）的触发必须是"不小心/意外"（随手接过甜食看也没看塞进嘴里），不能是主动想吃；复位靠习惯性动作（随手够酸梅干）。温柔形态越体贴，复位后"翻脸不认账"越好笑。
8. **全员不知情结构**：当设定为"角色不知道男主秘密"时——删净一切"确认/知情/怀疑成真"内容（台词里的"第三次变身"、日记里的"眼神好像他"、备忘录里的"确认同一主体"都要改）；保留"最接近真相者"（数据吻合+"待验证/待查"，缺证据不下结论，留 EP 末悬念）；怀疑线用"闪念即自我否定"（"怎么像那个笨蛋……我在想什么啊，疯了吧"）；"以为对方听不懂才说真心话"是最强反讽点（花穗对狗说"反正你也听不懂"）。
9. **后宫番角色结构**：四推（主记忆点，每人 3 段 15-30s 可切片）+ 搅局者（竞争感，不占配额）+ 功能配角（世界观，1-2 句）。每轮改稿数一遍有名有姓的女性角色，超过"四推+1搅+2功能"就要砍或降级。
10. **写作红线**（项目沿用）：无心理描写、无括号暗示、台词口语化、动作即潜台词、所有内容可从视听角度拍摄。

## 标准改稿流程

1. 读取用户原文附件，以它为底本建立新版本文件
2. 列出"用户授权修改清单"（用户原话里点名要改的部分），写进版本说明
3. 逐项执行修改；其余段落原样复制
4. 全稿过一遍段落衔接，补 `[过渡·X]`
5. 跑自检清单
6. 交付：文件 MEDIA 链接 + 改动对照表（改了什么/为什么）+ 完整剧本正文

## 自检清单（每轮改稿必跑）

- [ ] 有没有改到用户没授权的部分？
- [ ] 有没有新增设定外的物品/规则？
- [ ] 每个角色出现的场景与其身份匹配？
- [ ] 所有段落之间都有过渡？
- [ ] 人设修正后，行为系统/切片/台词/进度表/术语全部联动更新？
- [ ] "知情"痕迹清零：确认/识破/怀疑成真的台词、日记、补记？
- [ ] 有名有姓角色数量符合结构（四推+1搅+2功能）？
- [ ] 双形态触发是"不小心"发生的？
- [ ] 版本说明写清本轮改动与沿用项？
